# 组员投稿

每位组员可以把自己用 DeepSeek（或其他工具）做的教学视频投到这里。成片要交，**制作过程也要交**：做过什么、优化了什么、还有什么没解决。这样大家能互相取长补短，验证过的好做法会收进[经验库](经验库.md)固定下来。

## 怎么投

把下面这句话发给你的 AI 助手：

> 按 `作品/投稿/投稿指南.md` 帮我投稿这条视频。

AI 会照着[投稿指南](投稿指南.md)建目录、填登记、整理制作记录、上传视频并自检。上传和推送之前会先问你。你要确认三件事：视频是不是最终版，你是不是完整看过，记录里写的是不是真的。

## 这里有什么

| 位置 | 内容 |
| --- | --- |
| [投稿指南](投稿指南.md) | 交什么、怎么上传、字段怎么写（主要给 AI 读） |
| [经验库](经验库.md) | 固定做法、待验证做法、已知坑、未解决问题，开工前先看 |
| [_模板](_模板/) | 新投稿从这里复制 |
| [_成员模板](_成员模板/README.md) | 第一次投稿时复制成自己的成员页 |
| `<GitHub 用户名小写>/` | 每位成员一个文件夹，第一次投稿时建立；里面是成员页 `README.md` 和各个作品目录 |

视频统一放在 GitHub Release 的 [`submissions`](https://github.com/gduf-community/ManiMind/releases/tag/submissions) 预发布里，仓库只存登记和制作资料。查看全部投稿和各自未解决的问题数：

```bash
python3 scripts/check_submissions.py --list
```

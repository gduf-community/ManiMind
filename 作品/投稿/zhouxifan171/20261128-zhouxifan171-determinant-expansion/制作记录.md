# 三阶行列式按行（列）展开

> 作者：周熙钒（@zhouxifan171）、林琳 · 场景：不对应场景库编号（`scene_id: null`） · 最终版本：v001 · 记录人：DeepSeek 整理，组员已核对

## 目标

给刚学完行列式定义、会算二阶三阶但只会按定义硬乘的学生（大学线性代数入门，也可作高中拓展）。先修：行列式的定义、二阶行列式、余子式的概念。

片尾观众应能：
1. 解释为什么同一个行列式按不同的行（或列）展开，结果相同；
2. 对着一个行列式，判断哪一行（或列）含零多、从而展开最省力；
3. 自己动手把 D = |2 1 3; 4 0 5; 1 2 6| 按某一列展开，算出 D = −15。

## 成片

v001，1:07（67.30 秒），1920×1080、60fps，H.264 + AAC，TTS 配音 + 画面底部烧录中文字幕（字幕已烧进画面，另无外挂字幕文件随片上传）。

分段（时间点取自 `源码/timings.json` 的节拍起点）：

| 时间 | 内容 |
| --- | --- |
| 00:00–00:08 | 提出：三阶行列式怎么算更快？可以按行，也可以按列展开 |
| 00:08–00:16 | 核心公式 A_ij = (−1)^(i+j) M_ij，左侧符号板联动 |
| 00:16–00:21 | 选第二行，因为它含一个零 |
| 00:21–00:31 | 4×A21：元素取出，划去第 2 行第 1 列，M21 = 1×6 − 3×2 = 0 |
| 00:31–00:36 | 0×A22，这一项仍为 0 |
| 00:36–00:45 | 5×A23：M23 = 3，A23 = −3，这一项 −15 |
| 00:45–00:49 | 三项相加，D = −15 |
| 00:49–00:58 | 换第三列交叉验证：3×8、5×(−3)、6×(−4)，同样 −15 |
| 00:58–01:07 | 结论：任一行、任一列都能展开；含零越多越省力 |

## 制作过程

按实际顺序：

1. **选题**：不对应场景库里现成的场景（线性代数部分只有 LA-005 行列式与面积、LA-015 正交矩阵、LA-020 二次型等，没有"按行（列）展开求值"的题），属于自选题。编排思路参考本仓库"讲解脚本 → 分镜 → Manim 动画"的做法（工程 README 首段自述）。
2. **环境**：Manim Community 0.22.1 + Python 3.13.14 + edge-tts 7.3.1 + imageio-ffmpeg 0.8.1（ffmpeg 9.0.2）。本机没有 LaTeX，所以全部公式与刻度都用 `Text` / `MarkupText` 渲染，不用 `MathTex`/`Tex`。
3. **先做无声版**：`scenes/determinant_expansion.py` 里先写好 9 个节拍的画面（`DetExpansionBase`），渲出无声、只带烧录字幕的 `DetExpansion.mp4`（67 秒），先确认画面与节奏成立。
4. **加配音**：`build_narration.py` 用 edge-tts 逐句合成（音色 zh-CN-XiaoxuanNeural，语速 −10%，音调 −2Hz），把每句转成 44.1k 单声道 wav 后用标准库 `wave` 量时长，算出每拍起点写进 `timings.json`；再把各段用 `adelay + apad=whole_dur` 补齐后 concat 成 `narration.wav`。场景每个节拍末尾用 `Scene.time` 补齐到累计时间点，声画因此严格对齐。
5. **改表达（徐鹏程老师意见）**：最初用 `Indicate`（放大再缩小）强调系数，紧接着遮罩把同一个元素盖掉，两段动作语义打架。改为：系数变红高亮 → 沿弧线"取出"落到右侧算式的系数位 → 之后才淡入遮罩划去整行整列 → 撤走遮罩时元素淡回原位并转灰（表示"已被取用"），行列式始终完整可读。
6. **修多音字**：旁白里的"行"都取"排"义，应读 háng，TTS 默认读 xíng。edge-tts 7.x 会把文本做 XML 转义，SSML 的 `<phoneme>` 透传不进去，于是改用同音字替换（`PRONOUNCE_FIX = {"行": "航"}`），只影响送进 TTS 的文本，字幕和画面仍显示"行"。
7. **合轨**：画面不重编码，直接把配音轨套上去（`-c:v copy -c:a aac -af apad -shortest`），避免二次压缩。
8. **另出慢速备选**：`DetExpansionSlow`（节拍 ×1.3、动画倍率 0.8，85 秒）留作备选，本次投稿交正常节奏版。

未留存的部分：与 DeepSeek 的完整对话和各轮提示词没有导出，所以本目录不设 `提示词/`（组员未提供）。中间的调试日志同样未保留。

复现成片（工程根目录，`manimtopo` 虚拟环境已激活）：

```bash
../manimtopo/Scripts/python.exe build_narration.py     # 出 timings.json 与 audio/narration.wav
./render.sh -qh                                        # 1080p60 渲染到 output/DetExpansion.mp4（已烧字幕）
ffmpeg -i output/DetExpansion.mp4 -i audio/narration.wav \
  -c:v copy -c:a aac -b:a 128k -af apad -shortest output/DetExpansion_narrated.mp4
```

## 可复用做法

- **做法**：画面节奏交给 `timings.json`（每拍一句旁白 + 累计起点 `cum`），场景在每拍末尾用 `Scene.time` 补齐到 `cum[i]`，配音与画面自然对齐，不用手挤 `run_time`。**适用**：有配音、节奏要稳的教学片。**证据**：`源码/determinant_expansion.py` 的 `DetExpansionBase.end_beat()`、`源码/build_narration.py` 的 `main()`。
- **做法**：没有 LaTeX 时用 `MarkupText` 的 `<sub>/<sup>` 排真下标（A_ij、M_ij），比用普通文本拼字号更接近课本。**适用**：本机无 MiKTeX，又需要下标上标。**证据**：`源码/determinant_expansion.py` 的 `fm()`、`截图/v001-0025.png`。
- **做法**：中文多音字在送 TTS 前用同音字替换（"行"→"航"），绕开 edge-tts 的 XML 转义；字幕仍显示原字。**适用**：edge-tts 7.x，SSML `<phoneme>` 不生效时。**证据**：`源码/build_narration.py` 的 `PRONOUNCE_FIX` 与 `speech_of()`。
- **做法**：表达"这个元素被取用"时，用"高亮 → 取出移到结果位 → 再淡入遮罩划行划列 → 撤罩后淡回转灰"这一串动作，不用 `Indicate` 放大强调。**适用**：展开、代入这类需要观众看清每个系数去哪了的推导。**证据**：`源码/determinant_expansion.py` 的 `DetExpansionBase`、`截图/v001-0025.png`、`截图/v001-0039.png`。
- **做法**：成片合轨用 `-c:v copy` 只套音轨、不重编码画面；同时把音色签名写进文件，参数变了自动重合成。**适用**：改音色/语速后重新配音。**证据**：`源码/build_narration.py` 的 `synth()`、`main()`。

# DeepSeek 隔离自主制作实验

本实验为 `deepseek-autonomous-20261020`，不覆盖上一轮失败。作者仍使用官方 `deepseek-flash` 非思考模式；公共事实、受众目标和通用质量标准保持相同，但从空白重新创作，不继承任何作者的旧稿、参考片、聊天记录或具体批评。

## 执行边界

`experiments/freeform_agent.py` 将模型返回的 JSON 动作解释为本地工具调用。模型自行决定写讲稿、写代码、精确替换自己指定的文本、查询已安装的 ManimGL API、渲染、按 cue 查看实际原帧和结束。协调者不选择修复内容，不改候选源码；精确替换的原文必须唯一匹配，否则原样报错。

不限制镜头数量、情节、构图、视觉元素或叙事模板。配音的实际时钟、运行库接口、安全边界与有限预算属于执行契约。修改讲稿或源码会清空旧渲染和自检覆盖；提交独立验收前须有完整当前渲染，以及每个 cue 对实际像素的作者观察。作者自检永远不等于独立发布许可。

模型只接收冻结公共输入、自己的当前源码/时间轴、最近8轮原始工具结果及模型自己的笔记。图像是作者所请求的实际帧或6帧联系表，没有主 Agent 的批注。逐步保留全部历史，最近窗口不是全部历史删除。工具不暴露任意 shell、文件系统浏览或外部网络。

渲染采用 AST 能力过滤与 macOS sandbox，禁止网络、其他项目/隐私读取，以及用户目录写入；允许当前媒体目录与系统所需缓存写入。API 密钥不进入候选进程。此机制不是对抗性安全平台；需要审计实际请求和来源链，不能仅凭配置声称绝对隔离。

## 预算与状态

上限48轮模型调用、8次实际渲染、10元高峰未缓存 API 估算。失败调用不隐式重试，原始用量照计；用 UTF-8 文本长度和宽松图像 allowance 预留下一轮费用，未知用量时停止。估算不是供应商账单，也不包含协调、独立审核、TTS、电力或人工成本。

## 本轮执行结果

自主作者已完成36轮调用和8次渲染，实际模型响应为 `deepseek-flash`。前3次渲染因候选代码/时间调用错误失败，后5次均完整生成121秒、1920×1080、30fps视频。作者13次调用分段检查工具，4轮根据图像继续修稿，最后重新观察所有7个 cue 后提交独立审核。

调用动作包括写讲稿1次、完整源码3次、逐字替换7次、接口查询2次、渲染8次、分段看图13次、提交2次。其中两次接口查询不符合工具参数契约；一次提交因为新渲染尚未覆盖全部 cue 被阻断。技术失败和无效工具调用均保留，没有隐藏重试。

原答与步骤记录已逐一核对；最终源码可从模型的完整源码输出及逐字替换动作重放得到，与实际第8次渲染源码一致。所有图像请求均来自该实验自己的原帧且哈希匹配，冻结工具指纹未改变。开始 API 实验后，协调者没有改候选、工具或给作者补充具体内容建议。

API 输入1,087,712、输出35,956 tokens，高峰未缓存估算 **2.463072元**，含全部36次调用，无未知用量。不是实付账单；不包含 Codex 编排/审核、TTS、渲染和人工成本。工具相关测试206项通过、1项跳过，其中有真实 TeX 和沙箱读写测试。

以上只证明自主执行与局部视觉修订链完成，不证明教学质量达标。最终发布状态以 `runtime/projects/deepseek-autonomous-20261020/review.json` 为准。该项目的历史默认合成文件名和收据通用说明不代表使用了参考片内容，作者归属以本协议和逐步骤来源审计为准。

### 独立验收：拒绝教学发布

审核实际查看4张联系表、28个采样画面和关键原尺寸帧，并额外检查16秒附近的落地动作。布局可读性通过预览门槛，但数学表达、叙事指代与时序未通过：

- 高度对比段画面只有 `h` 与 `2h` 两条轨迹，时间标为 `T` 与 `sqrt(2)T`，旁白却说“两球飞行时间仍然相同”。没有呈现所指的另一组同高度双球，形成关键图文矛盾。
- 高度加倍且横速不变的图中，水平跨度比约1.583，时间比却标为约1.414，未解释尺度差别。
- 第二段先出现“结果：同时着地”，之后才开始下落，违反本轮冻结的先观察再揭示结果的时序标准。
- 总结中仍有下标字形丢失、文字残留等非阻断性的瑕疵。

作者自己的图像自检漏掉了这些问题。独立结论没有返给作者用于追加修稿，本轮没有人工修正内容。只允许另行审核后展示带全程警示的完整实验样片，不进入合格课程合成入口。审核未听审、未连续看全片，也没有学生理解测试。

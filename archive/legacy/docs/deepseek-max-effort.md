# DeepSeek 全推理隔离制作

新实验 `deepseek-max-effort-20261021` 从空白任务开始，不采用任何旧讲稿、源码、视频、审片意见或主对话。公共任务仍为平抛运动；事实包与通用验收标准保持不变。此项验证 DeepSeek 在充分推理与自主返工下能否完成作品，不是与 Codex 同预算的排行榜实验。

## 配置与边界

- 官方 `deepseek-flash`，2026-10-21 官方文档对应 V4.1-Flash-1017，支持图像理解；V4 Pro 不支持看图，因此不作为本轮视觉自主执行模型。
- 作者和独立审片者均为 `thinking=enabled`、`reasoning_effort=max`、`top_p=0.95`。
- `max_tokens=393216` 为官方每次响应上限，不要求模型填满。使用流式响应，保留原始最终回答、实际模型标识、用量、结束原因和推理字符计数；不向用户展示内部推理。
- 金额、作者调用次数、渲染次数、审核循环次数均不设上限。停止条件是模型完成提交、独立审核通过进入最终验收、模型明确停止、用户中断、服务/协议故障或不改变内容而连续执行三次完全相同的失败动作。
- 请求的网络等待超时为3600秒，单次渲染沿用工具的2400秒超时。这些是故障保护，不是整片制作时间/花费上限。服务异常不隐式重试收费；未知费用保留，不记为零。
- 原有隔离工具、静态代码筛选、macOS 沙箱、当前渲染全段自检及最终独立发布门禁保留。隔离不是对抗性安全证明。
- 作者每次收到本轮自己的完整动作记录，不继承其他实验或会话；审片者不接收作者笔记、自评或历史评论，只看公共任务、当前代码/实测时间与实际帧。原始评语直接返给作者。
- 审片格式错误沿用一次原始错误自修复，不手工修补语义。原有两段/六帧批次只是媒体工具接口，不固定教学镜头数量或构图。

## 状态生命周期

| 路径 | 写入者 / 消费者 | 生命周期与失效 |
| --- | --- | --- |
| `runtime/projects/<id>/max-effort-protocol.json` 与 `isolation.json` | 编排器 / 作者、审片者、验收者 | 首次请求前冻结；配置、实现、公共契约变化须新项目 |
| `runtime/sessions/<id>-generation/request-*/` | API执行器 / 审计、作者 | 单次请求、原答、用量与流进度；失败和中断均保留，不覆盖重发 |
| 同目录 `agent-state.json`、`review-cycle-state.json`、`step-*/` | 工具执行器 / 下一轮作者与编排 | 本轮进度和完整动作历史；改稿或改码使当前渲染及自检覆盖失效 |
| 同目录 `max-effort.lock` | 编排器 / 运行入口 | 活跃进程互斥，正常退出删除；异常残留须核实进程后恢复 |
| `runtime/sessions/<id>-independent-review/` | DeepSeek审片请求执行器 / 作者、验收者 | 分段与全片原始意见，绑定当时媒体；修改后只能作历史反馈，不能放行新片 |
| `outputs/<id>/` | 原答机械提取器及渲染器 / 用户、审片者 | 本轮讲稿、源码、派生媒体、证据和成本；不混入其他作品 |

## 运行

```sh
manimgl_env/bin/python -m manimind.experiments.freeform_max_effort \
  --config configs/deepseek-max-effort-20261021.json
```

API审片通过只进入 `awaiting_external_review`，不自动创建最终批准或成片。独立最终验收仍须覆盖真实媒体；若失败，禁止伪称通过。抽帧/文本核查不代表连续观看、听审或学生理解测试。

实现仅新增入口，不修改冻结的旧实验及其生成内容。成本按官方用量分作者/审片者汇总，给出空闲缓存与高峰非缓存估算区间，包含失败记录，不包含 Codex 工程与最终验收、配音和本地计算。

官方核对来源：[模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[输出上限](https://api-docs.deepseek.com/api/create-chat-completion/)。

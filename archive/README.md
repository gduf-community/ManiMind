# 历史归档

这里保留 ManiMind 早期设计、模型实验、实施计划和迁移说明。当前项目入口在[首页](../README.md)，观看入口在[作品目录](../作品/README.md)。

| 分区 | 内容 |
| --- | --- |
| `legacy/` | 经安全扫描的历史文档、早期开发说明和设计资产 |
| `local/` | 本机账号/主机资料与接管原文，Git 忽略 |
| [迁移清单](migrations/20261103/manifest.json) | 每批 old/new/SHA、公开范围和实际移动状态 |

正文迁走后，少量旧路径保留兼容导航，便于既有文档链接继续找到历史原文。它们是入口，不是原正文的重复副本。

## 当前仍在使用的历史来源

旧模型实现、旧导数源、原声、基线及原生审核资料仍参与当前制作核验，按[冻结清单](../ai/migrations/README.md)保留在制作路径。本次物理归档数以迁移清单中的 `physically_moved` 为准。

本机历史播放包和对比材料另见[作品历史版本](../作品/历史版本/README.md)。大型媒体通过本机播放目录或负责人确认的发布位置取得。

第三方资产与许可证完整保留在 `resources/`，本轮未调整。

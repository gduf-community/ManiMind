# 动态视觉 如何让观众理解变化

## 结论

动画有用时，它让观众追踪一个关系；动画失效时，它只是让内容短暂出现又消失。创作工具需要允许显隐、重排、局部放大、轨迹、对照和静止停留，但不应要求每个镜头都使用这些手段。

我们真正要审核的是：观众能否回答“变了什么、没变什么、为什么这个变化重要”。

## 证据及边界

de Koning 等在 2007 年的心血管动画实验中发现，提示关键过程有助于理解和迁移；2011 年关于提示与播放速度的研究却没有发现理解和迁移测验表现的相应差异。提示是否有效取决于材料和任务，不能推导出“加高亮一定提高学习效果”。[2007 原始论文](https://repub.eur.nl/pub/12095/PSY-2007-005.pdf)、[2011 原始研究摘要](https://repub.eur.nl/pub/74287)

Heer 与 Robertson 的实验研究支持适当的图表转场帮助追踪对象和估计数值变化，同时发现复杂的多阶段转场可能增加错误。研究测量的是图形感知，不是整门课程的理解。[原始论文，2007](https://sites.stat.columbia.edu/gelman/communication/HeerRobertson2007.pdf)

## 区分三种变化

| 变化类型 | 例子 | 观众需要的线索 |
|---|---|---|
| 对象或状态变化 | 小车移动、参数改变、样本增加 | 哪个对象、什么变量、时间或参数如何推进 |
| 表示变化 | 同一个量从几何图转为公式，直角坐标转另一表示 | 前后对应关系，哪些含义保持不变 |
| 观察方式变化 | 镜头放大、坐标轴改尺度、裁剪视野 | 是对象变了还是镜头变了，原位置在哪里 |

如果三种变化同时发生而没有建立对应，观众可能把缩放误认成斜率改变，把图形换位误认成数量改变。解决方法可以是分步，也可以是保留参照、提供并排视图；不必强制所有运动依次串行。

## 让变化有可追踪的对象

可考虑保留名称、颜色、形状、位置或轨迹中的部分线索。重点是对象身份可辨认，而不是所有视觉属性永远不许变化。

例如割线趋近切线时：

- 固定研究点，让第二个点沿同一条曲线接近，帮助辨认谁在移动。
- 横纵增量与差商在语义上连接；数值显示是辅助，不代替这个连接。
- 当两点视觉上太近时，可以局部放大，也可以改用差商表达式或误差图。
- 点重合的极限状态不能偷偷执行除以零；画面应区分有限间隔与极限对象。

这些是作者的可选工具。静态的三幅对照图，在某些任务中可能比持续运动更好读。

## 关键状态不只是动画终点

当前“最后 15% 保持不动”把可读时间统一留给终点，但教学关键状态可能在中间。

以 `f(x) = (x-1)^2 + k` 为例，`k` 从负变正，两个交点、相切、没有交点是三个不同情形。若相切只出现一帧，旁白虽然提到了，观众却可能未能识别它。可采用精确停在 `k=0`、留下边界快照、在旁边保留三状态对照等方式。

这不等于规定所有边界必须停两秒。审核应查看边界是否可感知、与讲解是否对应；停顿长度由内容复杂度、读数和实际语音决定。

## 用语义对齐音画

建议在创作时允许作者使用事件或语音锚点，例如：

```text
“固定这个点”       -> 被指对象已出现，并能与另一点区分
“让另一点靠近”     -> 对应运动开始
“注意这段高度”     -> 高度、标签或局部视图可见
“现在恰好相切”     -> 真正的相切状态可被辨认
```

锚点是可编辑的制作辅助，不是所有作品必须提交的统一分镜数据。其作用是避免用整段旁白时长代替句子与视觉事件的对应。

一次失败的对齐可以有多种修法：改语句顺序、移动画面事件、增加比较图，或者改变分段。系统不应只允许加长镜头末尾。

## 怎样选择表示

| 想让观众理解的事情 | 可以尝试 | 特别要防止 |
|---|---|---|
| 前后变化 | 同一对象连续运动、前后叠影 | 对象身份丢失 |
| 多个情形的区别 | 并排比较、小多图、逐个展开 | 不同坐标尺度造成误读 |
| 局部机制 | 放大、剖面、拆解 | 放大后失去全局位置 |
| 代数等价 | 对应项移动、逐步替换、静态推导 | 视觉变形伪装成合法等式 |
| 过程与累积 | 轨迹、区域累计、事件标记 | 把参数变化当真实时间 |
| 边界或突变 | 精确事件、快照、状态提示 | 插值越过边界却口播“此刻” |

选择 2D、3D、Manim、HTML 或其他工具应服务表达。空间结构才是三维镜头的理由，不是为了显得制作成本高。

## 作者引导

> 请选择能让观众跟踪关系的表示方式。可以改变构图、保留关键状态、放大或暂停，也可以用静态对照。需要时提示哪个量在变、哪些条件不变；音画尽量在语义上互相支撑。不要求运动量，也不限制镜头形式。

## 审核与试验

看实际视频中的关键变化区间，不只看开头、中间、结尾三张图。确定性工具可以标出候选异常，最终判断应能定位到时间与对象。

可用测试包括：在一个未见过的参数值之前暂停，让学生预测结果；要求说明刚才到底改变了什么；要求辨别对象变化与坐标缩放。首次测试可比较连续动画和静态对照，而不是预设动画一定胜出。

阅读停顿、空白过渡和低运动段可能是有意设计。除非它们导致实际信息缺失或故障，不能仅凭像素变化少而判失败。

# 底层逻辑 如何从现象走到可迁移的理解

## 结论

“讲底层逻辑”不意味着从公理重建整门学科，而是解释本片结论为什么成立、依赖什么条件，以及换一种情境后哪些部分仍然成立。

动画可以让理由被看见，但几个数值例子或一个漂亮形变，不自动构成一般性证明。

## 证据及边界

Chi 等让学生阅读人体循环系统文本并生成自我解释；被提示解释的学生较对照组取得更大的前后测增益。研究规模较小，材料是文本。它提示我们检查观众能否自己解释，而不只询问“是否听懂”。[原始论文，1994](https://education.asu.edu/sites/g/files/litvpz656/files/lcl/chideleeuwchiulavancher_3.pdf)

Gentner 等关于谈判案例的研究显示，直接比较案例有助于抽取关系并迁移。把这个思路用于数学视频是设计推论：不仅给多个例子，还要帮助观众辨认共同结构。不能把跨领域推论说成已经在本项目验证。[原始论文，2003](https://groups.psych.northwestern.edu/gentner/papers/GentnerLoewensteinThompson03.pdf)

## 把不同性质的知识分开

| 知识性质 | 适合的解释 | 容易出现的偷换 |
|---|---|---|
| 数学定义 | 动机、含义、例子与非例 | 声称定义是实验推出来的事实 |
| 数学命题 | 条件、等价变换、证明或明确范围内的直觉 | 用几个图形样本证明所有情况 |
| 物理机制 | 模型假设、过程、量之间的关系、与测量的联系 | 把模拟结果当独立实验证据 |
| 经验结论 | 研究设计、数据范围、不确定性 | 把相关性动画画成因果关系 |
| 计算方法 | 为什么这样操作、何时适用、如何检查 | 只有步骤，没有依据与失败条件 |

这类区分属于事实审核，不限制作者先展示哪一种材料。

## 二次方程的一条完整解释路线

下面是为当前失败题目设计的示例，不是新工作流的固定答案。其他作者可以选择完全不同但同样成立的路线。

### 从能直接看懂的结构开始

研究 `f(x)=(x-1)^2+k` 与方程 `f(x)=0`。固定平方项，只改变 `k`：

- `k<0` 时，方程要求一个平方等于正数，有两个不同实数解。
- `k=0` 时，平方只能为零，有一个不同的实数解，也是二重根。
- `k>0` 时，平方需要等于负数，在实数范围内不可能。

图上可以对应抛物线与横轴相交、相切、相离。真正的理由是平方的非负性和正数有两个互为相反数的平方根，不是“画出来恰好如此”。

### 让配方成为表示转换

从 `x^2-2x+c` 变成：

```text
x^2 - 2x + c
= (x^2 - 2x + 1) + c - 1
= (x - 1)^2 + (c - 1)
```

作者可以让补出的 `+1` 与补偿的 `-1` 形成可见对应，也可以使用静态排版。重点是总值没有被改变，原来的常数 `c` 不能直接当顶点高度。

再推广到首项系数为一的情形：

```text
x^2 + bx + c = (x + b/2)^2 + c - b^2/4
h = c - b^2/4
Delta = b^2 - 4c = -4h
```

这里才给“判别式”命名，就能把一个待记忆的符号与已经理解的高度联系起来。若受众已经掌握配方，也可以从这个等式直接进入。

### 不把特殊情形冒充一般情形

对于实系数、`a != 0` 的一般二次方程：

```text
ax^2 + bx + c = 0
等价于
(2ax + b)^2 = b^2 - 4ac
```

右边就是判别式。左边平方的性质给出三个实根情形；`a != 0` 保证从 `2ax+b` 回到 `x` 是一一对应。

一般抛物线的顶点纵坐标为 `h=-Delta/(4a)`。当 `a<0`，顶点是最高点，不可继续套用“最低点高于横轴就无根”的讲法。还要区分“没有实根”与“没有任何复数根”。

本轮使用现有 ManimGL 环境的 SymPy 复核了两种配方等式、一般方程变形与顶点高度恒等式，均通过；也核对了 `k=-1,0,1` 的不同实根数。符号计算验证的是代数关系，不验证讲解效果。

## 用反例揭示条件

`x^2+1=0` 没有实根，`x^2-3x+1=0` 有两个不同实根。两者常数项同为正数，说明只观察 `c` 的符号不充分。

审核可以问：观众看完能否解释这个差异？如果只能背出两次判别式计算结果，而不能联系配方或平方的值域，本片宣称的“理解为什么”还没有获得支持。

## 从同一个机制迁移到其他主题

| 主题 | 值得显现的结构 | 不宜省略的边界 |
|---|---|---|
| 瞬时速度 | 非零时间差下的差商，以及它的极限 | 有限平均值不等于极限；并非处处可导 |
| 线性变换 | `v=xe1+ye2` 与 `T(v)=xT(e1)+yT(e2)` 的联系 | 保持加法和数乘是前提，任意形变不满足 |
| 条件概率 | 条件改变了被计数或归一化的样本集合 | 条件概率不等于反向条件概率 |
| 力与运动 | 在给定模型下合力与加速度的关系 | 速度方向与加速度方向不能混同 |

## 审核怎样判断

核对成片中的关键主张及其支持：是定义、推导、实验、模拟还是类比？是否存在条件被省略、等价关系中断或由局部推广到整体？

类比可以很有启发性，也有失效处。审核应指出具体的错误推广，而不是要求作者不能使用类比。学生验证则使用解释、反例与迁移问题，不只检查记忆。

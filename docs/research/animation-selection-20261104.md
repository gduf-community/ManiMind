# 哪些知识最值得做成动画

2026-11-04。面向高中数学、高中物理及大学数学课程的选题研究与第一轮内容规划。

## 结论

项目转向可用于课堂的精选动画场景库。完整知识体系继续帮助我们安排先修、深度与衔接，制作顺序则由理解收益决定。各科独立建库，数量开放，选题随试教持续增补。

“值得做”有两个同时成立的理由：学生在这里确实需要解释；动态画面能让某个关键关系变得更容易推理。题难、内容重要、画面好看，分别都不足以单独决定立项。

## 研究给我们的启发

| 依据 | 可以据此采用的思路 | 使用范围 |
| --- | --- | --- |
| Tversky 等的动画研究 [R01](https://sites.stat.columbia.edu/gelman/graphics.course/animationijhcsproofs.pdf) | 画面的结构应对应概念的结构；复杂或快速变化可能让观众抓不住关键过程 | 动画设计依据，不能推导出所有动画都优于静态图 |
| PhET 设计研究 [R02](https://phet.colorado.edu/publications/archive/Phet%20Interview%20Paper.htm) | 用预测、探索和学生口述发现表征误读，实际观察学生怎样理解 | 研究对象为交互仿真；线性视频应另做验证 |
| 机械波学生理解研究 [R03](https://arxiv.org/abs/physics/0207092) | 同一学生可能在不同问题中混用正确与错误模型，应检查迁移 | 支持将波的传播、质点运动、叠加分清，而非用一次答对判掌握 |
| [MIT Mathlets](https://mathlets.org/mathlets/) | 把同一数学关系的不同表示联动，参数变化具有明确的读数和后果 | 参考机制和教学活动；页面许可包含非商业条款，商用作品自行实现 |
| [Seeing Theory](https://seeing-theory.brown.edu/) | 概率与统计中的重复试验、分布和估计可以通过集合过程呈现 | 作者案例，网站已归档；效果仍需按我们的受众检验 |
| 3Blue1Brown [特征向量](https://www.3blue1brown.com/lessons/eigenvalues/)与[导数](https://www.3blue1brown.com/lessons/derivatives/) | 一个对象在变换中持续可辨，符号由已有几何关系长出来，先修决定解释深度 | 借鉴讲解方法，使用原创场景、例子和音画素材 |

本轮优先级是教研判断，不是学生学习效果的测量分数。现有公开研究和案例也没有为下面每一条场景提供独立的有效性证明。

## 高中选题结合教材与教辅

教材与课标负责范围、术语和知识主线；教辅负责暴露迁移难点、条件变化和方法选择。随后再问：这道题里，究竟哪一段值得动画化？

### 数学参考高考数学你真的掌握了吗

已核对清华大学出版社的[旧版书目](https://www.tup.tsinghua.edu.cn/booksCenter/book_05653802.html)、[完整公开目录](https://www.tup.tsinghua.edu.cn/booksCenter/bookcatalog?id=05653802)和[前言](https://www.tup.tsinghua.edu.cn/booksCenter/bookpreface?id=05653802)，并确认[新高掌平面几何与三角函数第二版](https://wqbook.wqxuetang.com/book/3263112)的官方书目。新旧版逐页对应尚未取得；本库不填猜测的页码或例题号。

这套参考让选题从“逐个介绍概念”进一步转向“看出解题结构”。优先研究参数改变时可行范围怎样变、交点怎样增减、递推怎样演化、几何量为何保持不变。场景中的演示路径、参数和出口题由我们设计；具体来源定位记录在各条数据中。

例如，恒成立可用连续参数扫描帮助发现限制最紧的位置，随后用最值论证覆盖整个区间；圆锥曲线动点可以呈现定值猜想，再给出代数证明。数值扫描与运动轨迹承担发现和解释，证明负责普遍性与遗漏情形。

### 物理参考更高更快地解题

用户指定的书目按《更高更快地解题：高中物理》追查。目前取得[上册书目记录](https://www.sanmin.com.tw/product/index/007956447)和自称该书主编的[作者公开课程信息](https://www.bilibili.com/video/BV1QV411X7nD/)。后者的当前合集对应另一本《问鼎高考》；只能作为作者方法线索，不能冒充本书完整目录。完整目录、具体版本与例题仍需正版书或用户提供的目录页核对。

因此物理库先把“模型、多过程、临界变化”落实为原创候选：板块与传送带的相对运动、绳松与脱轨、弹簧碰撞、带电粒子跨场边界、线框进出磁场。它们是我们依据物理关系提出的场景，不声称逐条出自该书。

### 课标与版本

[华南师范大学基地](https://pmc.scnu.edu.cn/a/20251127/25.html)提供 2025 修订物理课标简介；[高教社的数学课标解读](https://xuanshu.hep.com.cn/front/h5Mobile/bookDetails?bookId=6a299900e119ac972940bbce)提供新版结构与目录。两者不足以完成所有条目的官方课程类别、考试范围和地区适用性判定。制作前由任课教师结合所用教材核准。旧教辅中的已调整内容，作为拓展重新定位。

## 五类高收益机制

| 机制 | 适合的内容 | 画面应让观众做什么 |
| --- | --- | --- |
| 同一对象跨表示 | 运动与图像、函数与导数、矩阵与变换 | 在两个表示中指出同一个时刻、点、向量或增量 |
| 条件改变与临界切换 | 根数、静摩擦、接触与分离、场区边界 | 预测下一阶段，并说出切换由哪个条件触发 |
| 难以想象的空间关系 | 截面、二面角、梯度、曲面积分 | 换视角后仍能辨认研究对象，完成新的空间判断 |
| 局部累积为整体 | 积分、功、卷积、通量 | 追踪一个局部贡献怎样进入总量，解释权重与单位 |
| 个体随机与集合规律 | 大数定律、抽样分布、置信区间 | 区分一次结果与重复试验分布，判断新的样本情形 |

公式动作也属于解释机制：变化前后的量要能追踪，运算条件要成立。只是把每行公式轮流出现，或把符号随意飞动，不能产生这些理解收益。

## 怎样取舍

立项讨论看五件事：理解障碍是否具体，动态过程是否必要，能否迁移到一类问题，能否在教学现场插入，能否用正确且可读的模型制作。

优先级分为“优先”“进阶”“待验证”。前者优先做试片；进阶项面向已经具备相应基础的学生；待验证项先补教研、受众或表示可行性。它们都不是制作完成状态。没有数量配额，也不要求各科或各模块数量相等。

暂不独立制作的内容包括：简单移项、例行代入、仅靠一张静态图就足够解释的比较，以及换数字但核心机制相同的变式。它们可以保留在视频推导或练习中。一个大章节也不能靠改名为“一个场景”隐藏多个独立目标。

| 内容取舍示例 | 更值得投入动画的部分 | 其他部分怎样保留 |
| --- | --- | --- |
| 平抛运动 | 同一时间内竖直速度增长及位移非线性 | 水平等距简洁展示，去掉无助理解的标尺搬运 |
| 方程与根 | 参数变化引起交点诞生、合并、离开定义域 | 例行求根写在推导或配套练习里 |
| 数列求和 | 项的索引怎样对齐、边界项从哪里来 | 简单展开与代入保持清楚，不逐字飞入 |
| 立体几何 | 视角转换后仍可追踪截面与角的定义 | 常规体积公式不单独包装一条视频 |
| 行列式 | 有向面积及退化如何对应代数结果 | 按行展开的重复计算用文字例题支持 |
| 假设检验 | 条件分布、尾部与重复试验中的错误 | 软件按钮和查表步骤作为操作材料 |

上述取舍会随受众改变。若试教发现一个看似基础的步骤恰是主要障碍，就回到该处补动态解释，而不是拿“基础略讲”作统一理由。

## 大学课程分别建库

| 课程 | 主要任务 | 与其他库的分工 |
| --- | --- | --- |
| 微积分 | 极限、局部近似、累积、多元变化与积分 | 本轮覆盖一元与多元；向量分析注明进阶，普通微分方程另建课程 |
| 线性代数 | 线性映射、子空间、分解与几何结构 | 特征向量归本课，统计解释归统计库 |
| 概率论 | 随机机制及其分布规律 | 大数定律、中心极限定理讲随机规律，估计方法另归统计 |
| 数理统计 | 用有限数据做估计、检验和模型诊断 | 置信区间与假设检验不混成“概率科普” |

参考 MIT [一元微积分](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/)、[多元微积分](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/)、[线性代数](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/)、Harvard [Stat 110](https://stat110.hsites.harvard.edu/)与 MIT [统计课程讲义目录](https://ocw.mit.edu/courses/18-650-statistics-for-applications-fall-2016/pages/lecture-slides/)。这些是课程结构参照，不代表国内各专业统一开课范围。

常微分方程、离散数学、数值分析、复变函数等列为后续独立研究方向，不挤进微积分或线代以完成名额。

### 相近主题怎样避免重复制作

| 场景组合 | 各自增加的理解 | 可以共用的资产 |
| --- | --- | --- |
| 高中导数与大学局部线性化 | 高中建立差商与瞬时变化；大学检查误差相对增量的阶数 | 同一曲线、增量与放大工具 |
| 高中条件概率与大学条件分布 | 高中从比较范围入手；大学处理权重、密度和条件化 | 样本筛选与概率质量表示 |
| 概率中心极限定理与统计抽样分布 | 概率解释标准化和的规律；统计解释估计精度与区间 | 重复抽样引擎和分布绘制 |
| 线代最小二乘与统计回归 | 线代解释子空间投影；统计解释数据误差假设和诊断 | 投影、数据点和残差对象 |

同一动画组件可多处使用；每一条视频都应有相对先修的新出口。若两个条目只有换名和换数字，合并为同一场景的变式。不同课程的对应关系保留，但不据此要求学生按本库的固定观看顺序学习。

## 哪些地方应先补证据

数学当前最需要核对新版教辅与旧版的改动，物理最需要取得指定教辅的完整目录和典型页。高中条目还要由任课教师确认本地教材、选考与拓展的具体位置。大学课程中的向量分析、基础随机过程等由专业课范围决定是否采用。

这些缺口影响的是选题的具体定位，不妨碍先验证一个原创演示是否讲清了关系。书目热度、作者声誉和考试难度不当作“学生一定需要本条动画”的替代证据。

## 下一轮如何验证

先做跨题材的小批试片：参数根数、传送带共速临界、积分基本定理、最小二乘、卷积、置信区间。原有导数、平抛、机械波、特征向量素材用于复用与比较，不自动标记为已覆盖新场景。

请任课教师判断是否解决真实教学问题，让目标学生在观看前预测、观看后解释，再处理一个改变条件的新问题。试教记录保留原回答和误解，不只记录“有趣”“好看”。有条件时用内容等价的静态解释做小规模对照；探索性试用不包装成教育效果实验结论。

返工优先修造成误读的表示、关键因果缺口和音画错位，再优化外观。保留已有有效推导与变量连续性，配音按完整意思推进，字幕只有一套。片长和镜头数量随解释任务变化。

# 教学研究证据台账

检索日期：2026-10-28。以课标发布机构、大学教学中心、论文原文/摘要、作者资源和模型官方资料为主。以下不是“所有结论都被实验证明”的清单。

证据类型：规范文件决定课程范围，不证明教法效果；综合报告/研究指南归纳证据但各条强度不同；实证研究有特定样本和条件；创作案例用于分析设计；工程资料只说明接口与实现。

## 检索失败与保留的不确定性

1. 人教社2020版数学PDF返回403；课程教材研究所对应PDF后续超时；学校托管2025版数学PDF搜索可见但打开404。没有以搜索摘要冒充通读新版全文。
2. 当前2025版课标的版本事实由S02-S04交叉确认；目录的逐条范围/水平/教材页码仍为空，不填造精确对应。
3. S13出版章未全文获取，S18仅摘要可读；不从这些访问结果摘取未看到的章节数字。
4. 没有学生样本、没有重新合成或连续听审当前三片；本轮给出的是研究与可验证方案，不是已证实解决收尾问题。
5. 本轮查阅不等于系统综述：未做预注册、全库筛选、偏倚统一评价。优先保留可以追溯的一手来源，后续根据教师/学生反馈补证据。
6. S23原论文全文访问失败，题录与S19转述分开记录；不声称本轮重查其样本清理、统计方法或学习成效。

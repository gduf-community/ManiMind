# 反复收尾感：定位与下一轮试验

日期：2026-10-28。状态：源码核对后的研究假设与试验设计；未启动GPU、未修改冻结生成参数、未更换用户选定V01、未宣称已经改善。

## 1. 用户说的不是“尾音不完整”

此前用户曾希望句尾读完整；现在反馈是每句话语气都收一下。两者不矛盾：字音完整是音节/词层面的要求，语义尚未完成时保留承接感是话语/段落层面的要求。

问题不应简单改写为“所有句尾不降调”。自然语言有小停顿、呼吸、强调和真正的结束。目标是让同一条推理听成一个过程，而不是每一小步都像完成一条公告。普通话声调还限制末字F0，不能以末字下降多少赫兹自动判断“收尾过度”。[S24-S27，来源见证据台账]

## 2. 已确认的工程事实

`src/manimind/postproduce/flexible_voxcpm.py:145`的`generate_kwargs`只传当前segment的text及固定参考音频/参考文本。`generate`在每段重新设定生成随机种子后，独立调用`model.generate`。没有把上一段目标文本/目标声音作为连续叙述上下文传入；同一V01参考不是前后文。

`src/manimind/review/semantic_focus.py:57`的排程器把每个完整WAV放在该focus起点之后，检查是否放得下；它不是段落韵律编辑器，也不检查关键词与动作是否同拍。最小间隔参数0.25秒不等于实际句间都只有0.25秒，focus之间距离可能更大。

当前交付alignment记录如下，比例为完整WAV区间长度/视频片长，不是VAD测得的纯发声率：

| 成片 | 片长 | WAV总长 | 区间占比 |
| --- | ---: | ---: | ---: |
| 电磁感应与能量 | 240秒 | 100.48秒 | 41.9% |
| 导数与局部线性 | 234秒 | 95.68秒 | 40.9% |
| 特征向量与不变方向 | 254秒 | 146.72秒 | 57.8% |

导数D03结束37.24秒，D04开始63.12秒，中间约25.88秒无计划旁白。期间有运动、转场、公式阅读等，不能把这25.88秒全称无意义静止；但声画碎片感不能只靠“整句未越窗”排除。数据来自当前三片`aligned-v001/2/alignment.json`，不是听感推测。

## 4. 四种粒度应分开

1. 教学步骤：一个需要看懂的推理或变化。
2. 动画事件：它的出现、运动、结果、回看。
3. 语音意群：一次完整的解释行为，可以跨几个步骤/字幕句。
4. 字幕片段：为阅读和同步分行，不决定模型必须重新起声。

例如“提公因子 -> 约去非零因子 -> 得到简式”可以保留三个动画事件，用一个连贯语音段覆盖；字幕仍按真实发声位置分为几行。段末才明显收束，段中允许自然短停顿。不要为每个focus都强制生成一条新WAV。

这需要新版本的“一段声音对应多个事件”契约；当前schema与门禁不能靠合并文本后假标成单一focus来绕过。既有原音、绑定、完整字音、独立审核和内容回归仍保留。

## 5. 下一轮最小对照，不重做整片

先选一段包含连续因果/代数的短解释，再选一段叙述性解释，覆盖两种语体。长度按完整意群选，不规定每段必须多少秒。此处不直接发起生成。

第一轮只改生成粒度：

- A：原分段独立生成，再拼接。
- B：完全相同的文字、标点、参考、模型revision、可比参数，一次生成同一意群。
- 两路都保留原音和每个实际调用；不隐瞒重复抽卡。原速比较，统一透明恒定增益，不剪末字、不拿crossfade掩盖字音。
- 用纯音频盲听判断段内承接，再看声画版。若给两路保留各自停顿，这是生成粒度的总效果；若另测匹配停顿版，要明确是第二个处理因素，不能混称单变量。

第二轮才独立测试口语改写、段落边界和合法标点的作用。将一串句号全部替换逗号既改变文本，也可能导致喘不过气，不能与第一轮混在一起归因。

示例仅说明口语关系，不是已批准替换稿：

“先把分子里的共同因子 h 提出来。这里 h 还没有等于零，所以分子、分母中的这个因子可以约去，剩下二加 h。现在再让 h 趋近零，就能看出这些割线的斜率在走向哪里。”

它应能听出“准备 -> 理由 -> 操作 -> 结果 -> 继续”，但不刻意做老师腔、播音腔或夸张情绪。

## 6. 声画同步如何处理

先保留科学上正确、可理解的视觉原型；语音意群生成后测量真实语音，标记关键动词/对象/结论的时间，再小范围协调停顿、显现与操作。不拉伸物理时钟，不让旁白对着已消失的旧式子解释。

关键指称可以使用强制对齐或ASR作为定位辅助，但公式、英文字母、希腊字母和数字必须人工听核。模型官方当前仓库提供可选时间戳路径不等于本地冻结版本已支持，更不等于时间戳真实正确。不能把按字数比例分字幕称为词级对齐。

最合适的返工单位通常是整个意群，而不是替换孤立半句话；修改后重核所有受影响事件和字幕。语音跨多个focus时，不能只验证段的首尾容量，还需检查段内引用的对象与动作。

## 7. 验收应怎样听

分别记录：字音/词语准确；公式读法；段内承接；真正结尾的收束；音色稳定；注意力引导；对着动画的落点。可以做盲选并记录偏好与原因，主观分数不当作学习效果。

必须连续听完样段，不能只抽每句中间、靠波形正常或逐句MOS判断段落。再放进完整场景检查：段内没有反复结束，段末也不会一直悬着；思考留白有明确任务。

尾部F0、时长、响度、静音间隔可以帮助定位异常，但有清浊音、声调、重音和噪声影响，不存在本轮已经证实的自动“收尾次数合格阈值”。英语停顿研究也不能替我们给普通话规定一个统一停顿秒数。[S24、S27]

## 8. 先改什么、不先改什么

优先验证连续意群与现有逐段方案，不先更换声线、不先微调模型、不先跑整条视频，也不把强风格提示当解药。若同文意群仍无改善，再拆查参考、口语结构和引擎能力。

本研究未授权覆盖旧计划或冻结worker。实现时另立版本，明确定义段落资产、事件映射、审核与失效规则；对照获用户选择后，才替换完整成片的声音。

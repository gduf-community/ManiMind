# 从课程体系到一条讲得清楚的视频

研究日期：2026-10-28。状态：第一轮研究与课程骨架，供教研讨论；不是已经实施的新执行器，也不是学校认可的完整课程。

入口：[证据与来源](teaching-sources-20261028.md)、[高中课程目录](../curricula/README.md)、[段落配音研究](narration-prosody-20261028.md)。

本轮接续[2026-10-20教学与视听研究](learning-video-20261020/README.md)，新增的是整门课程依赖与学习进阶、可填充目录、单元/课题出口和当前V01逐段生成的工程定位；不覆盖旧研究的历史实施状态。

## 1. 核心判断

目前不宜继续按“选一个知识点，独立写一部完整小电影”的方式扩量。应先定义整门课希望学生形成的概念与能力，组织依赖和迁移，再决定每节新增什么、调用什么、在哪里需要慢下来。

课程目录不是教材标题的抄录，也不是视频播放列表。至少要同时表示：课程要求、知识依赖、学习进阶、诊断与补救、媒体覆盖。它们不能混成一个完成状态。

最重要的区分：

- 教过不等于掌握；视频看完不等于学会；模型审片通过不等于学生理解。
- “简单运算可以简洁”不等于“新概念中的关键联系可以省略”。
- 旧内容重现应增加新联系、检验迁移或激活记忆，不应每次从头再教。
- 单课不必从生活故事开始，不必先一般再特殊，也不必每隔几秒提问。
- 动画先行应指视觉推理优先，不应指第一次静音渲染的所有停顿永远不能调整。
- 教学步骤、动画动作、语音段落和字幕行是四种不同的粒度。

这些判断是结合课程标准、学习科学与当前工程的设计综合，不是某篇论文给出的统一制作公式。[S01-S09、S16-S20]

## 2. 依据与证据边界

已核实：2025年已有中小学课程方案和课程标准日常修订；西南大学2026年培训明确使用高中数学2017年版2025年修订，华南师大教材研究基地也列出高中物理2025年修订。不能把2020版当作已经核实的最新版。[S01-S04]

本轮目录以可核验的高中学科结构和知识依赖组织，2025版存在性与实施动态已核实，但最新数学全文链接出现404/超时，物理新版入口访问受限。故所有课标条目级覆盖、必修/选择性必修归属和当地教材映射仍需逐项核验。2020版可用内容只作基础结构参考，不声称完成2025版全面对齐。

学习科学来源包含综合报告、实践指南、实证研究与创作者原课。研究对象有中学、大学和实验环境，不能把大学课堂的平均效应量直接换算为我们的高中视频收益。3Blue1Brown与PhET是设计案例，不是其风格一定更有效的因果证据。[S05-S23]

## 3. 整门课怎样构建

### 3.1 先从“能做什么”倒推

先写课程结束后学生能解释、判断、建模或解决什么，再写能证明它的任务，最后安排知识与活动。目标不能只写“理解导数”“掌握牛顿定律”。例如：面对两条位置曲线，能判断同一时刻谁更快，并解释为何高度不等于速度。[S06、S07]

区分四类目标：概念解释、操作技能、模型/策略选择、迁移与边界判断。同一视频可以兼顾，但不能用一个计算结果代表四类目标都达成。

### 3.2 六层组织，避免只有章和节

| 层 | 要回答的问题 | 典型产物 |
| --- | --- | --- |
| 课程 | 学完形成什么能力；面向谁 | 范围、受众、目标、标准版本 |
| 概念主线 | 哪些思想反复长大 | 变化与不变、相互作用、守恒、函数与表示 |
| 单元 | 解决哪一类完整问题 | 单元核心问题、综合表现任务 |
| 课题 | 本节相对先修新增什么 | 理解增量、误区、退出检查 |
| 解释过程 | 观众怎样从已有模型走到新模型 | 观察、预测、联系、推演、反例 |
| 媒体 | 哪种表现最能显出这个联系 | 动画、静图、旁白、字幕、互动/实验 |

课标/教材顺序是学校实施视图；知识图是依赖视图；推荐播放顺序是学习路线视图。三者有关，但不必完全相同。例如三角函数、向量与物理运动要建立跨学科桥梁，不要求两个完整学科目录强行排成同一条线。

### 3.3 图中的边不应全部叫“先修”

- 硬先修：没有它无法解释本节，如速度变化率与加速度。
- 表示先修：会知识但不熟当前表示，如首次读速度-时间图。
- 演变：保留旧结构、改变条件，如一维运动到二维运动。
- 迁移：同一模型换情境，如重力做功与电场力做功；相似处和失效处都要标明。
- 对比/边界：容易混淆、需要并置，如合力与作用反作用、概率与频率。
- 复现：隔一段时间再调用，以检验和巩固，不形成先修循环。

先修子图可以查环，教学的回访与交叉联系本来就可形成回路，不能为了拓扑排序把这些联系删掉。

还要区分知识逻辑顺序与实际学习进阶。前者说明推理上依赖什么，后者说明目标学生可能怎样改变原有解释、需要什么支持和经历。目录里的前后关系目前是教研假设，需经真实任务和学生反馈修订；不能因为知识图没有环就称已经得到最佳教学顺序。NRC的跨年级框架也强调核心观念随学习经历逐渐深化，而不是逐年叠加互不相干的事实；这里借鉴组织思想，不移植美国课程范围。[S30]

### 3.4 维护“概念进阶”而不是只维护词条

以变化率为例：

1. 会读一段变化量及单位。
2. 会用比值描述一段区间的平均变化。
3. 能辨认图像斜率与变化率是同一关系的两种表示。
4. 能解释缩小区间时的趋近，不把零除零当答案。
5. 能把局部直线近似与导数联系。
6. 能在新函数/新情境中判断此思想适不适用。

这几级不应全部塞进“导数概念”一条。反过来，后面用导数研究单调性也不需要把平方函数差商重新推六遍。课程条目应记录首次建立、练熟、迁移、反思的不同职责。[S05、S08、S09、S30]

### 3.5 学过以后，什么时候可以略讲

| 学生状态/内容变化 | 处理建议 |
| --- | --- |
| 首次出现或明显误解 | 建立对象、联系和理由，给可操作的辨析 |
| 学过且可顺利提取，意义未变 | 用短提示激活，直接调用；提供回看入口 |
| 学过但跨度大或提取失败 | 插入小桥梁或补救支线，不让整门课一起倒退 |
| 公式相同但物理对象/符号角色改变 | 明确对应关系，不以“前面讲过”跳过迁移 |
| 旧条件不再成立 | 用反例或比较讲清边界，不能套用旧结论 |
| 多个熟练成分首次组合 | 重点展示如何协调，而非再分别讲基础定义 |

这里判断的是学生能否使用，不是系统是否已经生成过那条视频。没有诊断资料时应标为受众假设，不能写“学生已掌握”。课堂版可由老师判断，自学版可提供小诊断与补救链接；两者不必强制同样长。[S08、S09、S13]

### 3.6 反复出现但不反复从零开始

建议采用“首次讲透、后续调用、变式验证、间隔复现”。回顾可以是一个判断、一幅旧图或一个关系，不一定是重复播放旧解释。例题支持可逐步淡出：完整示范 -> 留关键一步 -> 独立选择方法。交错比较更适合已有基本区分能力后，不是把所有新题型一开始混在一起。[S10-S12、S14]

## 4. 如何决定详略与拆集

### 4.1 把时间给理解阻力

需要展开的通常不是算式最长处，而是：新对象看不见、原有直觉错了、表示发生切换、几个量同时变化、条件容易偷换、结论需要跨两步以上才能连上。

可压缩的是已经熟练且在本节意义不变的运算或线性比较。压缩时保留能追踪的中间关系，不逐符号念式子，也不通过装饰性移动延长显然步骤。

不要用固定“难点占60%”“一节只能有一个概念”“每镜20秒”作为生产要求。规划时写出为什么这里需要时长；审片时检查学生是否有依据跟上，不检查是否命中某个比例。

### 4.2 拆分依据是可完成的学习任务

可以拆集的信号：出现第二个独立的新概念链；需要换一种表示体系；先修桥梁超过本节主线；观察与推导各自都需要充分注意；不同受众需要不同深度。

每集应有一个可用结论，不在等式变形中途机械切断。上集解决“是什么/为何”，下集解决“怎样计算/何时适用”是一种选择，不是所有课题的固定分法。能合讲的内容不为凑目录拆成碎片。

| 课题 | 可行分工 | 不宜处理 |
| --- | --- | --- |
| 平抛 | 上：同一时间下两方向变化如何合成；下：由时钟关系得到轨迹与预测 | 每集都重新详讲匀速运动；或上集只放一条抛物线 |
| 导数 | 上：平均变化率到共同极限；后续：计算规则、局部线性/应用 | 一集首次引入h、极限、缩放坐标、误差界、不可导全部等量讲 |
| 电磁感应 | 磁通变化判据；方向；大小；能量分别有自己的任务 | 一条短片同时承担微观受力、两套推导、楞次定律与能量完整首讲 |
| 特征向量 | 大学线代：先建立不变直线，再求解，再用分解 | 当作高中课标条目；未建立矩阵变换就展示一长串消元 |

已有三条片可以作为相应单元的素材候选，不能直接等同于这些课程条目已完成。以后拆集要做内容回归，保留有效推理，不用更短代替更好。

## 5. 单课怎样推进

### 5.1 开头：产生一个值得解决、而且有能力接住的问题

可用真实现象、两种预测冲突、旧方法失效、两个相似例子不同结果、一个需要解释的图形或一个简洁任务。故事和悬念只是手段；不需要硬加角色、夸张反转、名人引用或“你知道吗”。

好的引入与结尾是同一问题，不是开头吸引注意后丢掉。必要的先修只在要使用时激活；标题可交代课题，旁白不必再念一遍课程目录。

例：教动量时，先让两个质量不同的小车交换运动状态，问“仅比较速度够不够”；比先宣读动量定义更容易暴露需要。但对完全不会读质量和速度的学生，应先补表示，不让猜谜代替基础。[S08、S15、S20]

### 5.2 中间：按课的任务选择路径

| 课型 | 可选择的推进路径 | 关键风险 |
| --- | --- | --- |
| 新概念建立 | 有辨识度的案例 -> 比较共同关系 -> 命名/定义 -> 新例检验 | 从一个例子直接宣称普遍成立 |
| 公式推导 | 明确目标与条件 -> 每步操作及理由 -> 回到图像/量 -> 检验 | 只保留符号动效，观众不知道为什么这样做 |
| 已知模型迁移 | 激活旧模型 -> 标出变与不变 -> 预测 -> 验证新适用范围 | 只说“类似”而不显示对应和差异 |
| 误区修正 | 引出可检验预测 -> 比较结果 -> 解释差异机制 -> 换例 | 只宣布原想法错了；制造无解困惑 |
| 复杂综合 | 先看完整任务 -> 示范分解与选法 -> 协调熟悉成分 -> 逐步撤支持 | 又把每个基础独立重讲；或只演示最终解 |
| 探究/实验 | 问题 -> 可控变量与测量 -> 数据/不确定性 -> 模型 -> 边界 | 把程序预设数值画出来当成独立实验验证 |

“从简单到复杂”最好是先隔离困难，再组合困难，不只是把数值越换越大。“从特殊到一般”适合建立直觉，但一般结论仍需论证；“从一般到特殊”适合已经有框架后的应用。两种方向可以往返，不应冻结为统一顺序。[S11、S12、S15、S19]

### 5.3 展开难点的一种检查办法

对一个关键结论，逐一问：对象是什么；改变了什么；保持什么；为何导致下一步；能从哪一帧/哪一步看出来；什么情况下不成立。

不是要求每个镜头把六问念出来，而是作者能回答、审核者能找到片内证据。例如“加速度恒定所以位移非线性”，不能只给加速度读数和抛物线终态；应让等时刻的速度增量、越来越大的位移段与累计位移互相对照。

### 5.4 给观众做一点真实的思考

可选预测下一帧、选哪个模型、比较两种解法、解释一个错误、补出关键关系。提问应影响后续解释，而不是每段末尾例行问“明白了吗”。静音思考时保留明确对象/问题；需要较长作答时允许主动暂停或配套任务，不把无提示长留白当作教学活动。[S10、S14、S16]

### 5.5 结尾：完成承诺并留下可迁移结构

回答开头的问题；用新情境或边界说明刚学到的关系有何用；指出本节在单元中的新位置。若还有下一集，可留下由当前结论自然产生的问题，但本集已经承诺解决的任务应闭合。

不必逐条重念片头目标和所有公式，也不必每集都追加测验。若本节只建立直觉，结尾不能暗示学生已会完整求解。例题成功、概念理解和可迁移能力分别核验。[S06、S07、S17]

## 6. 动画、公式、旁白如何协作

### 6.1 每种媒介承担不同工作

画面显示对象、空间关系、过程与不变量；旁白引导注意、说明联系和理由；公式压缩定量关系；字幕支持听辨和回看。它们互相指向，不是把同一段文字放在四处。

难点需要对齐“关系被理解的时刻”，不只是句子在可读窗口内。说“把这一项移过去”时，应让观众看到原式、操作和新式；若变形早已结束，再说这一句，只能算解释终态，不是动作同步。[S18、S19]

### 6.2 建议的可选声画节拍

对象可辨认 -> 旁白提示要看什么 -> 关键动作/比较 -> 留结果以理解 -> 必要时回到整体。可以先预测再动，也可以先展示异常再解释；关键是同一认知任务不断线。

不要把所有句子一律安排在动画完成之后，也不要让新公式的展开与上一结论的长讲解竞争。有限的预留和局部回放可以服务理解，整段无任务的等待不能靠“给观众思考”自动合理化。

### 6.3 表示之间要有桥

- 物理：实际情景/理想模型 -> 同一时钟下的运动 -> 图像 -> 物理量与公式。
- 数学：具体例子 -> 可观察结构 -> 符号表达 -> 推理 -> 新例/边界。
- 公式变形：保留对象身份；解释相等的理由，不把移动本身当作证明。
- 颜色、单位、坐标含义连续；换图时交代哪部分仍是同一对象。
- 放大、重标度、参考系改变需要可理解的映射；不能只靠底部免责句防误解。

已知表示可以简洁调用；首次出现的坐标系、统计图或向量记号应先让学生会读。控制注意力不等于删掉解释，复杂过程也不必永久在全屏展示所有读数。[S12、S18-S20]

### 6.4 高级感是解释清楚后的表现控制

稳定的排版层次、适当的线宽/对比、运动连续性、克制的镜头和声音统一性，有助于观看；装饰、术语密度、长公式和不停运动并不自动提高教学质量。参考3Blue1Brown应更多看其如何调用前面课程、构建问题和串联表示，而非复制黑底与配色。[S21、S22]

字幕保留用户需要的一套，并检查遮挡与时机。多媒体冗余原则不是删除字幕的理由，尤其涉及中文公式读法、听力可及性与自主回看时；应削减与当前任务无关的常驻文字。[S18、S19]

## 7. 兴趣、困惑与“讲得太顺”

兴趣可以来自可解释的预测落差、亲手判断、一个简单模型覆盖多个现象，以及发现旧方法的边界。不必把严肃知识包装成剧情，也不必让普通人对每句内容都表现惊叹。

流畅观看可能产生已经理解的感觉。课堂研究提示主观学到多少与测到的学习可能不一致，因此“觉得好看”“编辑打高分”“学生能解释并迁移”应分开记录。[S16、S17]

探索式开头和明确示范并不互斥。对有能力尝试的核心问题，可以先让观众作预测再比较；对陌生术语和基本操作，可直接示范。先问题后讲解的收益依赖问题设计、后续整合与受众，不能简化为“老师越少讲越好”。[S11、S15]

## 8. 视频只是课程的一部分

面向学校更适合交付“课题视频 + 先修与目标 + 教师使用建议 + 学生任务/答案依据 + 来源/模型条件 + 修订记录”。一条动画不能代替所有课堂讨论、操作实验和独立练习。[S07、S10、S20]

建议同时支持三种使用视图，而非制作三套冗余内容：课堂投屏时老师可停在关键问题；自学时能找到先修补救与章节；复习时直达关系和边界。主片可以共享，播放包装和配套任务不同。

学校、教材版本、年级进度不同，目录应提供映射，不宣称替代所有学校的教学计划。高考难题专项、大学拓展与共同基础分别标记，避免把偏难技巧当作所有学生的基础先修。

## 9. 对本项目工作流的建议，尚未接入

建议的新输入链是：

课程版本与目标 -> 单元/课题定位 -> 受众先修假设或诊断 -> 本节新增理解与退出证据 -> 解释结构 -> 动画原型与口语草稿互审 -> 真实视觉审查 -> 段落语音 -> 事件级音画与连续听审 -> 字幕审查 -> 学生/教师试用反馈。

这不是要求配音牵着动画走。先确认视觉解释成立，再允许为自然讲解调整局部阅读节奏；不改科学运动规律，不为旧时间窗强切语句。变化后沿用现有来源绑定、独立审核和内容回归，而不是绕过门禁。

### 创作端给引导，审核端查事实

| 位置 | 引导/审核关注 | 不应变成的限制 |
| --- | --- | --- |
| 课程定位 | 当前新增理解与先修出口是否衔接 | 统一要求所有课重推全部基础 |
| 单元/单课规划 | 说明哪些展开、哪些调用及理由 | 固定幕数、分钟数、钩子比例 |
| 视觉 | 关键因果/表示转换能否在真实过程看懂 | 动作越多分越高 |
| 音画 | 所指对象和操作在讲述时是否可用 | WAV在窗口里就自动通过 |
| 语音 | 段内承接、段末收束、公式读法、连续听感 | 每句都必须不降调；固定停顿时长 |
| 课程效果 | 能解释、辨析、迁移；暴露失败原因 | LLM评分代替学习结果 |

建议作者只拿当前课所需的长期摘要：先修出口、单元脉络、误区、术语、有效旧素材。本轮分镜、失败语音、审核分歧留在session。不要把整套课程所有稿件每次全塞进上下文。

未来新增运行状态需另行设计写入者、消费者、生命周期与失效规则；本轮仅提供版本化编辑资料，没有新自动调度或学习者画像。目录中的空资产不代表待运行命令。

## 10. 如何验证这套设计没有欠拟合或过拟合

选相连课题验证，而非只拿同一条平抛反复打磨：一条基础建立、一条熟悉知识的迁移、一条含反例或复杂组合。至少再用数学与物理不同类型检查，不能只靠一个模板跨题套用。

建议先完成一个小单元闭环，例如“速度 -> 加速度 -> 平抛”，另选“函数图像 -> 平均变化率 -> 导数”作跨学科检查。小规模形成性访谈可先找少量学生，让其边看边解释并记录卡点；这只帮助找问题，不足以证明普遍效果。正式比较需要匹配先修、不同但等价的前后测、延迟迁移检查和适当的样本/设计。[S07、S17、S20]

评价分开：科学正确；解释可追踪；实际声画；连续听感；理解表现；兴趣与负担。不能用一个总分掩盖某个关键误解。保留旧片和学生原话，改动只针对证据支持的问题，不把单个学生偏好升级为所有视频的硬约束。

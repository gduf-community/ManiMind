# 一起参与

协作仓库为 [gduf-community/ManiMind](https://github.com/gduf-community/ManiMind)。本地当前制作进度由维护者核对后统一更新到协作分支。

## 可以做什么

- 教研：补充先修关系、科学条件、例子和课后能解释的问题
- 动画：改善一个推理过程、公式变化或图形与读数的联系
- 审片：按课次、版本和时刻记录具体问题
- 工程：补测试、改善工具与运行体验、整理可复现资料
- 文档：让新成员容易找到作品、课程和制作步骤

## 提交一个修改

1. 先与负责人确定课次、目标和文件范围。
2. 使用独立分支；Agent 分支沿用 `codex/` 前缀。
3. 保留基线与失败尝试，说明改动影响哪些课、哪些阶段。
4. 运行对应测试；画面修改附实际截图或候选片。
5. 提交 PR，写清问题、修改、验证结果和下一步。

当前导数八课正在并行返修。课程原生路径和绑定文件由主控协调；仓库目录整理使用单独的迁移清单。

## 资料如何分享

源码、小型 fixture 和公开文档放 Git。完整视频上传本仓库 GitHub Releases，在[作品目录](../作品/README.md)给出逐条下载链接与版本。原始请求、账号主机信息、私人素材和迁移包保存在本机证据区，公开摘要另列来源与裁剪方式。

参与工程协作的 Agent 从 [AGENTS.md](../AGENTS.md)读取执行规则；组员日常从本页和[制作流程](开始制作.md)开始。

# 整章合并时钟

`postproduce/chapter_package_clock.py` 是版本化编码适配器，不修改已冻结的 `chapter_package.py` 或既有课片。原始模块SHA固定为 `67a5d1d489bdf8c91b98692b2bca2d5db1f8e75046d432537ca557625f15a784`；每次调用有独立私有命名空间，没有跨Agent隐式共享状态。新contract为 `chapter-package-frame-clock-v2`，实现绑定保留原六文件并加入适配器与聚焦测试。原有来源、身份、独立章节/媒体批准、真实帧、解码、Desktop发布门禁不变。

## 修复范围

实际 `package-v002` 合并失败：原八片合计92805帧、3093.5秒，原输出实际落到25fps、77340帧、3093.6秒，音轨3093.589秒。原失败视频和pending保留，没有改成通过记录。

新编码只连接视频帧，按已验证30fps的原帧序号建立连续时钟，显式30fps输出。声音不串接AAC解码补齐：从每课已审alignment及完整原WAV逐样本重建，与其原`voice-mix.wav`相等后完整写入全章PCM，再一次AAC编码。不裁切、缩放、变速、重烧字幕，不删除任何原声样本。新candidate guard在发布前重新核对原WAV、位置、每课mix和整章样本，不能靠修改收据掩盖混音变化。

## 调用

新请求除原字段外显式包含 `frame_clock: ordinal-30fps-original-pcm-v1`，使用新package版本。失败或未知结果不复用目录，不自动重放。

```bash
python -m manimind.postproduce.chapter_package_clock prepare --request /absolute/new-request.json
python -m manimind.postproduce.chapter_package_clock assemble --plan /absolute/plan.json --review /absolute/assembly-review.json
python -m manimind.postproduce.chapter_package_clock release --plan /absolute/plan.json --review /absolute/media-review.json --desktop /Users/pengweitai/Desktop/新的整章目录
```

模块API与原版同名，另有 `native_namespace()` 供独立审核以同一版本门禁核验报告。API不会生成任何审核批准。

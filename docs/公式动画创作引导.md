# 公式动画创作引导

本页给新制作和返修提供可选择的表达方向，不固定布局、轨迹、秒数、公式数量或角色。已冻结作品沿自己的版本合同验收；这些原则帮助作者提前发现问题，不用来改写旧审核结果。

## 先想数学关系

先问观众需要跟住哪个量、当前做了什么运算、结论在什么范围内成立，再选择移动、复制、强调、替换或图形联系。同字形可以承担不同角色；同一个数学对象也可以在不同表示中保持身份。分配、合并和约分等一对多/多对一关系，应让运算本身说明来路，不能仅凭字形相似猜对应。

从具体例子走向一般形式时，区分可推广的角色与例子特有的数值、条件和结论。具体点的计算结果留在具体点的式子里；推广对象出现前，先处理副本中不再适用的部分。反方向代入时，把通用式和当前取值的对应说清，最终数值承接已经完成的代入与运算。

## 选合适的活动对象

需要前后对照时，可保留可读历史，让相关变量或完整项从真实源位置进入新角色。原位更新适合直接更新活动式，不必叠留一份同坐标的旧式；要保留前式时，可把它放在独立可读的位置。复制和原位替换各有用途，不以“始终保留所有旧层”为模板。

完整的分式、因子、函数输入或乘积，往往比分散字符更容易追踪。可保持对象稳定、只更新关系符号或局部项；新旧相反关系分别退出与进入，也可能比字形扭转更清楚。关键在于观众能看出数学变化，不是动作的数量。

安排路线与显现顺序时，留意移动项是否擦过条件文字、未完成的分式是否已经连上结果、相消后留下的项是否仍可辨。数学过程可以处于组装状态，不要求每一中间帧都像终态教科书公式；但对象、运算与适用范围应能沿过程理解。

## 时间服从理解

已有基础可以紧凑调用，新的表示、非线性变化、复合关系、极限和证明桥梁要有足够观察与阅读时间。片长不是教学目标，更多动作也不自动带来更多解释。

保留完整意群原音时，用实际子句与当前画面求排程。需要时可在新版本调整阅读和变形时段；保留模型关系与必要科学时钟，不为了旧总长压缩难点。原音确实无法适配时保留失败并选择明确返工，不截句、变速或仅把大focus窗口写成通过。

## 用真实过程检查

作者先看首次重要公式构建，再看本课难点和条件转换，尤其检查变化前、过程中和落位后。原生几何、TeX选择器和排程测试有各自作用，不能替代看实际渲染。重复失败的局部可先用复用同一实现的短真实探针调试，完整成片仍需正式审核。

独立首看判断当前画面是否成立；另一个上下文的内容回归比较有效推导、条件、单位、图形联系和变量身份是否退步。终态正确或单独质量通过，不抵消过程中适用范围混淆或解释功能丢失。听感、发音和学生理解分别验收。

维护者写本页；消费者为作者、协调者与审核者。生命周期为后续制作引导；新任务按受众和实际依赖选择，原则更新不追改冻结输入，也不证明任何具体视频已经合格。

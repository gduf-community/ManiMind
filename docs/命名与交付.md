# 作品命名与交付

观看目录让人一眼看懂学科、主题、版本和课次；制作目录保留机器使用的稳定标识。

## 播放包名称

整组目录采用：

```text
学科-单元名称-版本说明-YYYYMMDD/
  00-单元名称-整章合集.mp4
  01-课题名称.mp4
  02-课题名称.mp4
  目录.md
  manifest.json
  制作资料/
```

单片采用 `学科-课题-版本说明-YYYYMMDD.mp4`。同一日期多次交付时增加 `v001`、`v002`。名称里的“静音预览”“配音字幕版”“候选”直接说明这份文件的观看状态。

## 成片、草稿、历史版

| 分区 | 收录内容 |
| --- | --- |
| [成片](../作品/成片/README.md) | 已有交付清单对应的完整播放包，列出版本及听审状态 |
| [草稿](../作品/草稿/README.md) | 当前正在制作、送审或返工的版本，更新实际进度 |
| [历史版本](../作品/历史版本/README.md) | 被新版替代的播放包和历史演示，保留原来源 |

诊断片、失败候选和模型对比材料进入历史/研究资料，单独标明用途。

## 制作路径和播放名称分开

`outputs/`、`runtime/` 中的原生文件继续使用原路径。人类播放包通过复制已核准的交付文件建立，以原文件 SHA256 和真实交付清单关联。对已命名的桌面包，本次仅登记，保持原文件与名称。

作品索引记录显示名、实际播放名、位置、SHA256、原生交付来源、审核阶段及听审状态。更名记录写出 old/new/SHA；更新作品时创建新版本并保留上一版。

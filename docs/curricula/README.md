## 版本与范围

初稿面向高中共同基础及选考相关内容的主要知识领域，并保留探究/实验和跨单元整合位置。不是只做有炫目动画的课题，也不把题型穷举、竞赛、大学线代混进高中基础。

2025年日常修订版存在性已由发布/实施机构资料核实。最新版全文、地方教材和条目级学业要求尚未完整取得并逐条核对；故这里不预填官方必修/选择性必修、学年学期、课时或考试适用性。`role`是我们的教学职责分类，不是官方课程类别。来源与访问限制见[证据台账](../research/teaching-sources-20261028.md)。

“初中已学过”的一般算术、代数、几何和基础科学另作入门假设；如目标学生不足，新增诊断/补救条目，而不假装CSV已经列完所有隐含先修。`requires`是当前识别出的主要同科先修，不是完备的全部依赖。它们需要教师检查，不能仅凭无环就称教学顺序合理。

## 目录字段

| 字段 | 含义 |
| --- | --- |
| id | 稳定课题ID；改标题不改ID，撤并时保留映射 |
| module | 内容单元；不强制等于某教材的一章 |
| title | 候选片名/课题名，可经教研修改 |
| role | 建立、迁移、应用、辨析、实验或综合等职责 |
| requires | 主要先修ID，分号隔开；空值表示从入门假设出发 |
| new_understanding | 本节相对先修必须新增的理解 |
| reuse | 应调用、不必从头详讲的旧内容 |
| exit_check | 看完要能完成的可观察任务，尚未实测 |
| split_hint | 可以拆分的语义边界；不是固定片数/时长 |

每行是一个可分配的课题插槽，不是必须一行一条视频。一条可以覆盖几行，一行也可分上下集；以后资产表用多对多映射记录覆盖范围和证据，不能只把MP4扔进去就标完成。

## 后续填充与生命周期

目录版本的维护者是课程负责人/教研者，消费者是选题、课题设计、作者和审核者。生命周期跨多个视频制作轮次；课标、教材、受众或先修出口改变时，受影响课题与下游设计需重新核对。不是把所有旧视频物理文件自动删掉或改成无效。

建议未来资产映射独立记录`lesson_id -> project_id -> version -> coverage -> review evidence`。课程进展与学生掌握分离，课程语义审核与技术媒体审核分离。当前尚未建立这个资产状态机，CSV也没有假填“通过”。

初次落地先选一个连贯小单元，不从第一行一路无人审核批量渲染。目录拆并、题名调整都允许；新增运行状态及执行接口要另做架构设计和测试，不能拿本研究当已经接通的工作流。

## 本轮校核后补充

独立审查后明确增加幂函数归属、单摆周期与测g、电容器充放电、油膜估算；同时补出函数最值、全概率和机械波衍射的课题插槽。实验条目要区分视频解释、学生真实操作和数据论证，不能用一段模拟自动代替三种出口。最新课标学生必做实验清单的逐项映射仍未完成。

电磁感应能量课修正为先看完整能量账，再把外力功率等于电阻热功率限定在对应的匀速理想模型中，不推广到加速和其他储能/损耗不可忽略的过程。

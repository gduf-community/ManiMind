## 怎样使用

每行是一个连贯的理解任务，可以包含多个镜头。选题时一起看场景问题、动态机制、先修能力和出口题；相同知识点可以有不同深度，但只换题目数字的版本归入同一场景的变式。

“优先”先做试片，“进阶”面向相应基础的学生，“待验证”先补教研或表示可行性。优先级随课堂反馈调整，不代表作品完成度。首轮候选不等于所有值得做的题已经找完。

高中数学结合《高考数学你真的掌握了吗》的公开目录筛选，物理沿《更高更快地解题》的模型取向继续研究。版本和访问范围见[研究报告](../../research/animation-selection-20261104.md)及[来源表](sources.csv)。完整知识背景仍可查[旧全科地图](../README.md#全科知识地图)。

## 教研数据

CSV 是逐项数据源；同名 Markdown 是生成的阅读表。每项包含：稳定编号、所属专题、场景问题、动画机制、先修能力、出口任务、科学条件、优先级、来源编号、具体定位，以及旧全科地图的参考 ID。来源定位区分书中公开专题、课程范围与自拟演示。

更新 CSV 后，在仓库根目录运行：

```bash
python3 scripts/check_animation_catalogues.py --write
python3 scripts/check_animation_catalogues.py
```

本库由课程负责人及教研者维护，供组长、作者和审核者选题；面向多轮制作长期使用。受众、来源或科学条件变化时重审相关教案。实际制作的项目计划、审核和媒体仍分别进入 `runtime/projects/`、`runtime/sessions/` 和 `outputs/`。

正式制作前把选中条目及来源快照纳入项目教案，再按现有原生课程协议准备输入。新场景 CSV 不替换旧课程解析器所需的九字段格式，也不改动旧片的绑定来源。

# 精选场景的备课与制作

选题入口是[场景库](scene-library/README.md)，知识衔接参考[全科地图](README.md#全科知识地图)。组员认领一个清楚的理解任务，再决定用几段镜头、多少篇幅讲透。

## 立项时谈清什么

写出观众会问的一个具体问题，指出动态画面能解释的关键关系。结合教材的概念与教辅的迁移难点，选择能代表一类问题的例子。明确学生需要的基础，用一个短诊断确认；学生不必按顺序看完我们已有的所有视频。

出口任务改变一个条件，检验观众能否自己预测、解释或推导。计算量较大的机械步骤可以交给文字资料，把动画时间留给模型选择、对象关系和难以想象的变化。

## 从问题走到解释

开头给出问题或现象，再通过对照、变化和推理推进。容易看出的关系简洁呈现；难点保留足够过程，并让观众知道此刻应看哪个量。问题不同，结构也可以不同。

参数扫描帮助发现临界位置，证明或物理条件负责说明为什么。保留端点、退化与约束改变等有实际作用的情况，把它们自然放在需要判断的步骤。对观众说清发生了什么，避免为了自保而插入一串与当前疑问无关的否定句。

场景表中的科学条件和来源备注用于备课，不逐条搬成片中口播。会影响当前推理的条件，在相应对象或转折处讲清；与当前问题无关的范围说明留在教研资料。

图形与公式讲同一个对象。重要推导追踪增量、变量和运算的来去，已有有效解释按内容回归保留。多视图在同一时钟下显示对应关系，装饰和镜头移动服务于观察。

## 配音与审看

先把动画中的思考过程做通，再以自然口语写讲稿。按连续意群生成配音，让逻辑还在推进的句子保持连接感；结论处再真正收束。根据实际声音调整指称时刻和停留，最后核对单套字幕。

独立审核者看当前真实画面和音画配合；返修时另做新旧内容回归。试教请学生完成出口题，再用误解改进讲法。片长、镜头数和每段词数不设统一模板。

## 对接现有工具

场景库是备课材料。按当前原生 schema 建立项目输入，记录选题编号、来源、先修与出口任务，继续走[制作流程](../开始制作.md)及[AI 执行导航](../../ai/README.md)。现有完整章节保留作素材；新立项按场景价值安排，不默认补齐整章。

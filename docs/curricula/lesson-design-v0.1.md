# 从目录生成课题卡，而不是直接生成视频

状态：编辑设计示例，未接入执行器。课题ID来自本目录CSV；字段表达建议而非固定镜头/秒数。

## 最小课题卡

| 字段 | 应写什么 |
| --- | --- |
| 课程定位 | 课题ID、版本、学校/教材映射状态、单元核心问题 |
| 受众入口 | 具体会做什么；哪些是假设、哪些有诊断依据 |
| 理解增量 | 本节新建什么联系；不只是列名词 |
| 退出证据 | 一个能区分理解与套用的任务及判断依据 |
| 先修调用 | 每项如何激活；何种失败需要补救；回看节点 |
| 关键难点 | 易错预测、表示跳跃、非线性、空间/系统关系 |
| 解释路线 | 选择的推进方式与理由，不规定所有课同一套路 |
| 声画关系 | 要观察什么、动作何时发生、旁白说什么关系、哪里留思考 |
| 语音意群 | 哪些教学步骤合为连续解释；哪里真正收束 |
| 范围出口 | 什么结论已成立；什么条件不可省；下一课接哪一步 |
| 反馈与回归 | 需教师/学生检验什么；修订不得丢失哪些教学功能 |

正式生成前还要将任务转成当前执行器真实支持的计划，不直接把此表假称为可运行新schema。

## 示例一：速度 -> 加速度 -> 平抛

### P01-02 平均速度与瞬时速度

入口：能用参考系、位移和时间描述运动；会读位置图像。新增：速度是变化率，瞬时描述来自局部区间，不是位置高度。

引入可比较两辆车在同一时刻的位置与快慢，制造“走在前面不等于跑得快”的可检验分歧。先让学生会读有限区间位移，再缩小区间；画面同时追踪运动对象与图像变化。这里尚不正式引入数学极限运算。

退出任务：两条位置曲线在某时刻同高但局部斜率不同，学生能判断谁更快并说出依据。失败若来自不会读坐标，回P00-03；若把高度当速度，补一次同高不同斜率的对照，而非把全部内容重讲。

### P01-03 加速度不是速度大

直接调用“速度描述位置怎样变”，新增“加速度描述速度怎样变”。不再长讲位移定义和两数相除。

用快但匀速、慢但加速两种运动对比，再处理方向与减速；只改一个比较因素以便看清关系。退出任务要包含速度与加速度方向不同的情况。这里的难点是层级变化与矢量关系，不是除法运算。

### P04-02/P04-03 平抛的上下集

调用已有水平匀速、自由落体和矢量分量，必要时只给一幅可识别的旧关系。上集新增同一时间的两方向状态合成，重点放在竖直速度增长和位移累积；水平两倍关系无需搬标尺反复证明。

上集结束，学生应能预测等时刻点列，并解释为何水平间隔相等、竖直间隔不等；不必已会完整求射程。下集以这些已建立关系推导轨迹/落点，重点是消去时间和初始条件，不重新详讲匀速。

这只是可行划分。若课堂已熟练二维合成，可合片或更快调用；不能让目录决定所有班级都看同一长度。

## 示例二：平均变化率 -> 导数 -> 局部线性拓展

### M12-01/M12-02 核心基础

用熟悉的函数表示提出局部变化问题；将图中两段增量与差商明确连接。差商简化时保留非零条件，动效配合操作理由；不能等所有符号移完后才说“现在移过去”。

出口不是背出f'(1)=2，而是能解释h趋零和h直接取零的区别，并能在一个新函数的图像中识别同样的问题。初学者首次读差商图时要交代轴的量，不能从原函数图无桥梁跳到m(h)。

### M12-07 局部线性属于另一层次

新问题是“为什么局部能用一条直线近似”。缩放坐标与误差是新增理解，不是前两课里必须顺带挤完的基础。如果单独讲，可充分显示同一缩放如何作用于曲线、直线和误差；若只在基础片点到为止，不应暗示已经证明完整误差界。

原导数样片覆盖这些不同层次，可作素材库；逐课验收前不能把整片标签挂上就标这些课全部完成。

## 示例三：电磁感应单元不再每片从电子讲起

| 课题 | 本节真正新增 | 后面可直接调用 |
| --- | --- | --- |
| P12-01 | 用磁通变化区分有场与有感应；闭合回路条件 | 磁通与变化的含义 |
| P12-02 | 由变化趋势到响应方向；增加与减少对照 | 方向判定机制 |
| P12-03 | 大小取决于变化率，不是磁通值本身 | 法拉第关系及适用说明 |
| P12-04 | 电子受力与宏观开路电压的连接 | 运动导体的电压/电动势关系与条件 |
| P12-05 | 外力做功如何闭合为电能和热；改变速度的预测 | 前面方向、大小与电路定律 |

P12-05不应重新花很长时间讲电子分离，却需要认真解释反向安培力与能量流。在匀速、无其他耗散且可忽略电磁储能变化的电阻回路模型中，外力功率才等于热功率；若导体加速，即便忽略摩擦和自感，也有`P外 = dK/dt + I²R`，不能把前一特例无条件迁移。储能变化不可忽略时还需相应的能量项。

比较两种不同速度的匀速工况，不等于假装加速过程没有动能变化。只有“式子都出现过”但能量流和适用条件未连接，仍不算讲清楚。

## 如何组织一小段连续旁白

一个推理意群可以跨“提出操作 -> 条件/理由 -> 过程 -> 结果”，但不必逐式朗读。字幕换行不触发重新生成；镜头换成下一表示前，让前一指称仍可定位。

不要预设每段固定长度或完全无停顿。真正的结论处收住，继续解释处保留承接；先拿同文对照验证，再决定如何实现多事件声音映射。

# 做好一课

一课从一个清楚的问题开始：观众已经知道什么，这次要多理解哪一层，片尾能解释什么。

## 选题与备课

从[精选场景库](curricula/scene-library/README.md)选择一个值得动态解释的问题，结合教材和教辅确认学生卡在哪里。用[全科地图](curricula/README.md#全科知识地图)核对先修，写下动画要揭示的关系和一个改变条件后的出口题；按学生实际基础决定详略。新制作按场景收益安排，各科数量开放，不默认补齐整章。备课展开见[场景设计](curricula/scene-design-v0.2.md)。

整理科学条件、术语、公式与易错点。已有视频返修时，先一起看基线，记下要保留的推理和有效画面。

## 动画与讲稿

1. 用对象、图形和公式把推理演示出来，保留每次尝试。
2. 实看完整动画，核对变量来路、运算、读数和文字布局。
3. 由另一位审核者看当前画面；返修课同时做新旧内容比较。
4. 依据已经看过的画面写口语讲稿，按完整意思组织段落。
5. 核对真实配音与画面的指称和节奏，再制作单套字幕。
6. 将审核通过的版本整理成播放包，更新[作品目录](../作品/README.md)。

动画、讲稿、配音和字幕可以分别返工。每次交接写清当前版本、已经检查的内容和下一步，由接手的人继续。

## 文件放在哪里

| 内容 | 位置 |
| --- | --- |
| 课程目录与教案原则 | `docs/curricula/` |
| 课程长期事实与计划 | `runtime/projects/<project_id>/` |
| 当轮协作、自检与审核 | `runtime/sessions/<session_id>/` |
| 每版源码快照、媒体与交付清单 | `outputs/<project_id>/` |
| 人能直接观看的播放包与名称 | [作品与命名](命名与交付.md) |

当前课程制作采用 v4.3.1 绘图配置和 v3 公式连续性监督入口。开发者与 Agent 可从 [AI 导航](../ai/README.md)查到精确命令、输入和各阶段审核协议。

## 反馈怎样写

给出课次、版本和视频时刻，描述看到了什么、哪里产生疑惑。数学或物理问题同时指出对象、条件与推理步骤。可直接以“第 04 课 02:16，外层变化率的来源看不清”这样的方式提出修改。

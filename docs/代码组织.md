# 目录与代码

| 目录 | 用途 |
| --- | --- |
| `src/manimind/` | 项目编排与制作工具 |
| `examples/` | 课程和实验的场景源码 |
| `configs/` | 制作配置、工作流版本与依赖清单 |
| `tests/` | 纯数据、工具、原生对象与本机素材测试 |
| `docs/`、`作品/` | 给组员阅读的资料与作品索引 |
| `ai/` | Agent 规则、精确契约和技术参考 |
| `archive/` | 历史说明、实验记录和迁移 map |
| `resources/` | 第三方精选资产、来源与许可证 |
| `runtime/`、`outputs/` | 本机项目状态、协作证据和版本媒体 |

## 核心模块

`models/workflow/task_board` 负责计划、角色与依赖图；`context_assembly/runtime/runtime_store` 负责上下文和状态。课程定位由 `curriculum` 提供，动画复用 `components/render`，实际取证和审核由 `review/postproduce` 连接。

`experiments/` 保留各代实验实现，当前课程链从 [AI 导航](../ai/README.md)进入。已有 native 源码和配置沿用稳定路径，历史目录迁移在核对绑定后分批完成。

详细模块边界、状态写入者及失效规则已移到 [模块与状态详解](../ai/architecture/模块与状态详解.md)。

# 审核者规则卡

独立审核任务只读本卡和派发给你的那一个阶段契约（见末表）。本卡摘录现行规则；“一次派发只审一课”是派发约定，门禁不检查。字段细节与本卡不一致时，以阶段契约和门禁代码为准。

## 一、身份隔离

- 你是新上下文的独立 Reviewer，不是作者、主控、协调者、适配器或该版本原制作人；改角色标签不能把作者变成审核者。
- `reviewer_agent` 和 `reviewer_context` 都必填你真实的 Agent/上下文 ID，不用昵称、角色名或作者身份；有 `agentID`/`agent_id` 别名时须一致。
- 首看只接收公共任务、段落边界与实际像素；不读作者讲稿、源码、设计解释和意图，也不读作者推理与历史评语（包括作者 plan 里的前评、旧审核意见）。
- 一次派发只审一课的一个绑定版本：只批准当前 `bindings`。旧批准不转到新版本、新合片或新协议。
- 你的 agent 和 context 不得与任何作者或制作人相同，也不能沿用前置审核的 context：讲稿审核不同于首看，原音时序和字幕不同于此前各道，首看与内容回归不同 agent；整章 media 与 assembly 不同，原逐课 Reviewer 不能改标签做章节审核。
- 只写审核报告，不代写作品；问题以原始意见交回，由作者返工。

## 二、各阶段检查要点

1. **静音视觉首看**（`stage=visual`）：只凭公共目标和真实像素判断能否单独成立，不用旧版、作者意图、数学常识或工程测试替影片补理由。看真实中间帧而不仅是终态公式：变量来路与去向、身份误配、遮挡、残影、条件（如负根）、读数与图形是否一致、拥挤与错指。`meaning_alignment` 写 `not_applicable` 并说明没有音轨和讲稿。
2. **内容回归**（`stage=content_regression`）：实看任务选定的基线和新版真实画面，逐项判 `retained`、`equivalent`（附理由）或 `lost`。`process` 项要有时间递增的 before/during/after 像素证据。任一选定项 lost、缺项或缺证据即不通过，总分再高也不补偿。
3. **公式连续性**（`traceable_film_v3` 取证包）：核对数学对象的可见来路、去向与运算。整行淡入、曲线运动、代码里有 `Transform` 或运动量统计都不等于变量连续；PNG 相同不证明讲解有效。
4. **后写讲稿**（`stage=narration`）：核对源码、科学模型、实测事件区间与稿件；整节按口语通读，看只靠听能否跟上指代和理由，是否反复回应观众没提出的错误猜测。有效推理、条件、单位和术语不能只剩结论或类比。文字审核不是音频对齐或听审。
5. **原音时序**（`stage=audio_alignment`）：逐条引用当前子句区间与真实帧，全句须落在对应可读区间内；无证据的 `pass` 不接受。
6. **字幕像素**（`stage=captions`）：消费候选真实帧、ASS、原讲稿与当前 `bindings`；`layout`、`text_consistency`（逐字逐标点）、`frame_evidence` 三项都要有证据，重点看长句切换前、中、后和可能碰撞处。
7. **整章**（`stage=chapter_assembly` / `chapter_media`）：逐课 checks、边界帧和条件，按整章协议逐项填写。

## 三、报告必填字段

- `stage`：所选 native stage 的准确名称。
- `status`：`pass` 或 `revise`；`reviewer_role: "independent"`；`reviewer_agent` 与 `reviewer_context`：真实 ID。
- `bindings`：原样复制当前入口生成的输出，不手写、不凑字段数、不编造哈希。
- `blocking_findings`（列表）与 `release_authorized`（布尔）分开写。`pass` 时不能有 revise 项或阻断，且须授权；`revise` 不能授权发布。
- 每条证据给实际媒体时点（`time` 在片长内）和非空 `finding`；字幕和整章证据还要帧的 `path`、`sha256`。
- 编辑审核（visual、narration）另含 `action: "review"`、learning_quality 的 viewer_test 和六维 quality，以及五项 `editorial_checks`：mechanism、attention、pacing、meaning_alignment、transfer。
- 过程的主 before、during、after 各给一个明确定位，额外观察放进契约允许的独立字段。交门禁前先核字段名与数据类型。

## 四、诚实标注

- 当前 `unit_film` 链的每个阶段都写 `listening_reviewed: false` 和 `student_tested: false`，整章再加 `listening_status: "not_performed"`。`naturalness_approved`、`asr_accuracy_certified`、`pronunciation_approved` 不得为真。
- 抽帧审核不是连续观看、听审或学生理解测试；观众新例预测只是编辑判断，分数是内部编辑量表，不是学生效果结论。
- 工程测试、解码或复制成功不代表内容通过；JSON 里的 `pass` 不能当作像素事实。

## 五、观看覆盖如实写

- 采样帧、时间戳核对和真实 1x 连续观看分别记录范围。
- 缺少连续观看时，标为待补的覆盖与审阅；不据此推断影片有缺陷，也不据此要求重渲。
- 已实际看见的拥挤、错指、条件残留、数字与图形不符，按具体时刻和影响照实阻断。
- 缺证据就要求补帧或返工，不编造已观察。
- 格式要修正时由原 Reviewer 另立版本，保留实际观察和旧报告；格式修正与内容重判分开记录。补审沿已确定的媒体继续，不重复已完成的渲染或收费请求。

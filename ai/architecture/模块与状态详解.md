# ManiMind 代码组织

当前目录说明见 `docs/代码组织.md`；本文件保存详细模块与状态协议。历史基础 CLI 的调用范围按 `ai/legacy-cli.md` 执行，课程制作以 `ai/README.md` 的当前 native 契约为准。

## 总体原则

- 当前仓库只承担“编排层”和“项目层”职责。
- HTML 动画、视频渲染、Manim 数学动画优先复用外部能力目录，不在本仓库重复实现。
- 所有可持久化状态都必须落到明确目录，不允许隐藏在临时脚本或未命名文件中。
- 任何结构性改动都必须同步更新 `docs/architecture.canvas` 与对应 Markdown 架构文档。


## `src/manimind/` 模块边界

- `postproduce/traceable_film_v3.py`：纯审核监督器，复用冻结v2实际PNG取证/像素和身份检查，补齐所有声明帧/联系表哈希及既存链接拒绝。监督器源码与原索引绑定派生审核包，而不混入无关几何依赖；其变更重新取证/审核，不自动重绘。当前v4.3.1绘图后的正式稿安装/静音发布走v3，生命周期见[当前监督入口](../../docs/formula-continuity-v3.md)。

- `postproduce/traceable_film_v2.py`：v4.3.1公式连续性监督门禁，保留v1诊断实现；绑定作者选定的重要动作及独立首看的实际身份/运算/过程帧，核对索引后实际解码当前视频同一时刻的像素，并要求首看/回归Agent与context都不同，再复用冻结`unit_film`正式稿安装与静音发布；后续来源链不变。`components/formula_transfer.py`从真实源坐标复制语义对象，保留旧式，仅编排公开原生动画。状态生命周期和旧CLI未自动升级的边界见[公式连续性](../../docs/formula-continuity-v2.md)。

- `experiments/chapter_workflow.py`：监督式整章的逐课阶段适配器，只复用现有独立渲染、讲稿、原音对齐与字幕门禁。课程范围在长期unit，协调锁与输入包在短期session，失败和版本媒体在outputs；不调用模型、不自批，也不自动重试未知副作用。`coverage_status`只检查所有约定课次是否齐全，不代替当前成片和章节审核。

- `models.py`
  定义项目输入、镜头分段、任务分发表、上下文记录和审核检查点的数据模型。
- `workflow.py`
  定义默认阶段、子 Agent 分发规则、上下文蓝图和审核关卡。
- `bootstrap.py`
  负责仓库级初始化目录与外部依赖路径检测。
- `main.py`
  提供最小 CLI 入口，便于后续接入自动化命令。
- `context_assembly.py`
  负责按角色和阶段装配上下文包，并支持提示词分段缓存。
- `task_board.py`
  负责执行任务状态机、阻塞依赖检查与验证关卡提醒。
- `runtime_store.py`
  负责项目状态、上下文包、任务更新结果的落盘与审计日志写入。
- `runtime.py`
  负责 `ProjectRuntime` 统一加载、快照回填与 `current_stage` 派生。
- `render/`
  负责把 Manim Worker 生成的代码写入可预测输出路径，默认调用 ManimGL CLI 并加载根目录 `manimgl.yml`，保留 ManimCE 兼容后端，并用 ffmpeg 抽取关键帧证据供审核使用。两套媒体目录分开落在 `outputs/<project_id>/manim/media/<backend>/`。
- `review/`
  负责对渲染证据、帧质量、跨帧运动、Manim 代码质量、公式-图形绑定与跨镜头语义颜色一致性进行确定性预检，并把失败的视频、抽帧、黑屏、低对比、低细节、跨帧几乎无运动、在 `always_redraw` 中逐帧重建 Tex、缺少解释性动画信号、公式缺少视觉 companion 或变量颜色冲突转成审核阻塞项；也提供不调用 LLM 的项目级质量审计 JSON 与人工审片 Markdown 摘要。
- `postproduce/`
  负责读取审核后的分段视频证据，按项目清单顺序生成 concat 清单并拼接预览成片；也负责基于旁白脚本和真实分段时长生成 SRT，把软字幕轨封装进 MP4，生成字幕烧录版审看片，并按平台使用 Windows SAPI 或 macOS `say` 生成离线旁白与音视频合成；不负责云端配音或第三方剪辑引擎内部实现。

精修试片 `postproduce/pilot.py` 保持在后处理模块内，复用 `render/` 生成审核用画面；逐句配音准备发生在镜头制作前，最终音画合成必须消费独立 Reviewer 的版本绑定审核。固定实验的配置、场景、状态生命周期与复现方式见 [velocity-pilot.md](../../archive/legacy/docs/velocity-pilot.md)，不替代主编排入口。

`postproduce/freeform_pilot.py` 提供人工监督的自由场景试片入口：制作前测量配音，允许原创连续场景，保留逐段像素审核与版本绑定后合成。它不规定镜头数量、画面布局或教学组件，也不改写原有隔离对照；本地源码执行需要显式授权，不是渲染沙箱。试片状态与复现见 [projectile-story.md](../../archive/legacy/docs/projectile-story.md)。

`postproduce/playback_package.py` 为已烧录字幕的审核后试片生成独立播放目录，不复制同名外挂字幕，避免播放器自动加载后叠字。只逐字节复制既有 MP4，核对交付视频、原审核哈希和音视频流，不修改冻结制作器或候选内容。输出清单由打包器写、观众和审计者读，随交付目录保存；媒体或来源哈希变化即失效，不覆盖已有目录，不新增审核批准。复现与限制见 [播放交付](../reference/playback-package.md)。

`experiments/model_benchmark.py` 是国内 API/学校 OpenAI-compatible 服务的有界同题对照入口；只复用 LLM client、ManimGL renderer、抽帧与独立审核合成关卡。`experiments/scene_support.py` 仅提供字形与逐句时钟，不实现教学图形。模型原回答和尝试日志在短期目录，固定教案与独立审核在长期目录，媒体及成本摘要在输出目录。模型配置、边界、生命周期及校内部署起点见 [model-benchmark.md](../../archive/legacy/docs/model-benchmark.md)。

`archive/legacy/src/manimind/experiments/model_dialogue.py` 保存有界的候选模型联合诊断/图像复盘，不执行回复或批准交付。共同规范通过 benchmark 的 `--design-brief` 冻结。`guarded_scene.py` 只采集标签包围盒，`layout_guard.py` 纯数据复核碰撞/边界/完整性，不含教学场景；通过独立 Reviewer 仍是合成前置条件。

## 受约束镜头组件

`scene_spec/schema.py` 定义严格的 SceneSpec 1.0 数据契约：数字多项式、枚举图元/读数绑定、三段单调非零时间间隔和有限节奏选择，拒绝代码、表达式、未知字段。`geometry.py` 提供小型坐标规划、直线与矩形裁剪和实际帧数据检查，不重写 Manim。`renderer.py` 将合法数据组合成原生 ManimGL Axes/Line/DecimalNumber 等对象，复用现有中文字形和 cue 时钟，逐帧记录标签、点、线和读数。

`scene_spec/experiment.py` 是独立有界验证入口，冻结任务、契约、profile、预算；LLM仅输出JSON。原回答保留在短期账本，原始数据不可手改；工程校准与真实模型试验分目录、分计数。每次渲染独立版本并绑定组件哈希；自动检查与独立 Reviewer 全部通过才合成。当前只覆盖非负位置的低阶多项式割线/切线镜头，不代替任意课程规划。状态归属与命令见 [model-benchmark.md](../../archive/legacy/docs/model-benchmark.md)。

`scene_spec/report.py` 从保留的请求、实际审核和成片重建汇总，区分结构有效、机械检查、首轮审核与修复后审核，不把有效JSON当成可交付视频。报告绑定来源哈希，保留失败调用的token消耗，未知单价仍为null。

`archive/legacy/src/manimind/experiments/model_comparison.py` 负责冻结同题生成配置、复制匿名原帧和构造无答案的审片输入，复用 `scene_spec/experiment.py` 与 `archive/legacy/src/manimind/experiments/model_dialogue.py` 执行有界请求。比较协议/独立标准在长期目录，候选原始回答在各自短期会话，输入媒体与派生报告在输出目录。不自动按关键词裁定语义，不将候选审片回答写成正式交付审核。

`archive/legacy/src/manimind/experiments/comparison_report.py` 为该实验重建有来源哈希的汇总报告，明确标记候选“可接受”结论与blocker列表冲突；语义得分仍消费独立Reviewer裁定，不按词频自动判分。

## 模型无关组件基础层

`components/catalog.py`区分通用对象、旧组合演示和整片模板，并声明当前配色/字体；`expressions.py`为受限数学树生成安全数值计算与SymPy公式；`plan.py`定义多镜头数据契约和共享参数时钟；`renderer.py`组合原生ManimGL；`typography.py`复用Pillow字形和ImageMobject，提供TTC字重、固定基线数字及实际位图源色采集，不重写字形/渲染引擎；`pipeline.py`负责不调用provider的版本化工程验收。CLI为 `python -m manimind.components.pipeline`，详细目录、状态归属和限制见 [组件基础层](../reference/component-foundation.md)。旧实验保留历史，不因新增组件层自动迁移或作废重写。

`archive/legacy/src/manimind/experiments/isolated_comparison.py` 提供组件内整课生成的预注册隔离比较：公共输入冻结、无上下文继承的作者请求、仅机器错误的一次修复、原答与成本证据。`isolated_media.py`复用组件渲染与后处理工具，统一配音并要求独立媒体审核后合成。两者不改写候选内容，状态边界见 [隔离对照](../../archive/legacy/docs/isolated-comparison.md)。

`archive/legacy/src/manimind/experiments/isolated_render_repair.py` 是独立授权的渲染后单次自修复扩展。其协议引用冻结基线和原始渲染报错，单独记账；不能修改基线或给候选内容提供人工建议。

`experiments/freeform_isolated.py` 是独立 API 自由创作试验，不限制教学模板。冻结公共任务和工具指纹、保留作者讲稿及代码原答、有限自修复、记录成本；`freeform_support.py` 只提供字体、实测时钟和逐句字幕。复用自由试片的独立审核发布关卡，作者自检不能放行。状态与限制见 [DeepSeek 自由创作试验](../../archive/legacy/docs/deepseek-freeform.md)。

`experiments/freeform_agent.py` 为新实验增加自主工具循环：模型选择写稿、精确改码、查本地API、渲染及分段看图。所有调用和失败留档，不读参考片、不手改候选，内容变化使作者审片覆盖失效；独立审核仍是成片前置。预算、隔离范围和状态生命周期见 [自主制作实验](../../archive/legacy/docs/deepseek-autonomous.md)。

`experiments/freeform_review_cycle.py` 为独立新项目沿用同作者原稿，加入异上下文的同模型分段/全片审片及原始意见返工循环。作者和审片请求分开记录、合计预算，媒体更新使旧评语失去当前验收效力；API 审片不直接写最终发布批准。状态与边界见 [独立审片返工](../../archive/legacy/docs/deepseek-review-cycle.md)。

`experiments/freeform_review_retry.py` 为新实验提供每组一次审核JSON结构自修复，只传原始报错，不修语义内容，失败历史与费用合并保留；不修改已冻结的旧执行器。

`experiments/freeform_max_effort.py` 为新的空白项目复用自主工具与独立审片，作者/审片均开启最高推理强度和流式响应，取消金额、调用、渲染、循环上限；不继承旧稿或历史评语，不改旧冻结实现。全量本轮动作、角色请求及成本分别留档，服务故障与重复无变化失败会停机，API审片仍无发布权限。状态与限制见 [全推理隔离制作](../../archive/legacy/docs/deepseek-max-effort.md)。

`experiments/freeform_team.py` 复用既有自由场景媒体与来源验证，增加同模型的主控、创作者、独立审片三角色；私有工作记录分离，原始委托和评语传递，未决请求阻止重复收费，独立审核全通过才机械适配现有合成门禁。状态、计时口径及故障恢复见 [三角色协作实验](../../archive/legacy/docs/deepseek-team.md)。

`experiments/codex_cli_team.py` 适配 GPT-6.1 Sol 的订阅认证及临时 CLI 推理，沿用三角色媒体动作、来源验证与独立审片；每轮原始事件、token、缓存和调用参数留在角色会话，账户快照与制作耗时单列。具体输入隔离和额度口径见 [Sol 订阅协作实验](../../archive/legacy/docs/sol61-team.md)。

`experiments/subscription_quota.py` 只读账户限额并保存订阅实验期间的原始快照与差值报告；不发送创作请求、不进入角色提示，检测刷新后停止跨窗口相减。

`experiments/learning_workflow.py` 在原三角色执行器之上增加通用版本化引导、密集时序取证、无源码首看与源码/旁白复核，以及开发题/留出题门禁；不修改旧冻结实验或候选内容。`review/learning_quality.py` 诊断字幕排版、验证有证据的固定量表及关键维度，不以像素运动量或关键词裁定教学好坏。长期study/profile/外部评估、短期角色记录和版本媒体分离，生命周期与命令见 [教学工作流迭代](../../archive/legacy/docs/learning-workflow.md)。

`experiments/sol_learning_workflow.py` 将上述教学与审核逻辑接到既有 Sol 订阅传输，三角色均为 GPT-6.1 Sol max；单独 study、候选与上下文，不迁入已中止 DeepSeek 的内容。运行入口与额度观察器一并冻结，账户采样不替代每角色 token 记录；复用原发布门禁，不允许误用旧后台入口绕过新审核。

`archive/legacy/src/manimind/experiments/sol_learning_v2.py` 修复v1审核装配中的字幕全文间接泄漏，只给首看者当前分组的无正文诊断摘要；源码/讲稿审核另开请求。测试在最终原生传输输入处验证排除规则，v1冻结实现和原答保留并标注偏差。v2沿用角色、媒体、审核与额度生命周期，新增模块本身也进入冻结指纹。

`archive/legacy/src/manimind/experiments/learning_background.py` 只负责Sol v2的防重复后台启动，记录独立启动适配器和参数哈希，不进入模型上下文；检查活跃进程、团队锁及未决检查点，不自动重发未知请求。

`archive/legacy/src/manimind/experiments/sol_learning_v3.py`批量返回本机接口查询与当前cue图像，成功渲染自动提供实际取证，但不自动记为模型已观察。独立像素首看和源码/时序复核各自全片逐cue举证并通过固定量表，减少分组重复调用而不跳过审核。后台入口新增`--engine sol-v3`并校验profile版本，v1/v2冻结实现不变。调用减少是否保持质量仍需真实成片回归。

`archive/legacy/src/manimind/experiments/deepseek_learning_v3.py`将同一v3 profile接到官方DeepSeek high传输，直接继承通用工作流，不继承Sol CLI适配器。复用冻结的无正文审核装配和双全片审核方法，批量取证语义不变；三角色请求、格式自修复及费用记录显式为high。新study和空白角色上下文，不改旧执行器或候选；后台启动检查进程、团队锁和未决状态。目录、状态生命周期与比较边界见 [教学工作流迭代](../../archive/legacy/docs/learning-workflow.md#deepseek-high-同工作流实验)。

`experiments/learning_runtime.py` 隔离ManimGL导入时的CLI参数并单独绑定执行适配器哈希；只对可证明未改变候选的只读API查询提供断点补完，不重发provider请求，不恢复未知副作用的工具。绑定与恢复记录的生命周期见同文档。

`archive/legacy/src/manimind/experiments/isolated_montage.py` 是独立审批后的实验对比剪辑，仅串接完整已审批单片与说明卡，不承担候选内容生成或修复。

`postproduce/voxcpm_audition.py`是VoxCPM2无参考试听旁路，调用官方公共API，不接入私人声音或复刻旧A。固定原文与三个种子，每个一次、不隐藏重试，保留原生48kHz原音；`voxcpm_package.py`只负责验证新旧来源与媒体、在新目录追加试听，副本仅沿用固定增益。专用安装器只写`.venv-voxcpm2`及VoxCPM2模型，维护运行器复用跨引擎GPU互斥量，拒绝在线Qwen，完成后归还并验明原服务身份。新组合包保留所有历史媒体，仍等待听审、不合成视频。状态和来源见[配音服务](../../docs/remote-speech.md#voxcpm2-无参考补测)。

`postproduce/voxcpm_narration.py`在用户明确选择合成音色后，复用冻结Vox试听helper，以自选V01及其原文作参考/延续提示逐段生成；不触碰真人声库，不改已审核讲稿。`visual_narration.py`复用原视觉与讲稿批准验证，准备独立长计划，按原始全句实际时长匹配语义事件；独立、哈希绑定的时序审核通过前不能混音或封装。发布只复制原视频码流、加入一条声音，不内嵌/烧录/附带自动加载字幕；可选SRT在独立support目录。部署、状态及限制见[视觉后配音](../../docs/remote-speech.md#选定-v01-后的完整配音)。

`components/formula_motion.py`以明确语义ID编排原生矢量Tex与TransformMatchingParts，支持重复字面的occurrence选择，禁用按形状猜身份的fallback，不复制引擎内部实现。`examples/projectile_formula_motion.py`是原片之外的监督精修示例；`postproduce/formula_refinement.py`负责版本化渲染、逐帧符号轨迹/像素、独立审核门禁及指定片段替换，保留原配音包；内部无损master校验其余帧，播放版用兼容H.264 High。状态、作者边界及用法见[公式连续推导](../../docs/formula-motion.md)。

`postproduce/formula_film.py`复用相同基础片验证，编排完整静音视觉精修：原时间轴只追加明确的代数事件，17句既有旁白逐一对照实际视觉锚点；独立Reviewer绑定全片、源码、逐帧运动及真实像素后才封装。视频和原AAC均复制码流，验证1080p30/3420帧、起始时间、音画时长及全解码，不自动生成新声音、不把监督精修当模型隔离成绩。长期计划、版本化媒体和短期审核继续分离。

## 视觉优先制作

`curriculum.py`提取版本化课程context，不推断学生掌握或限制教学幕数。`postproduce/unit_film.py`作为独立监督入口接入schema3意群与多focus排程，`review/meaning_units.py`验证段内原文与多个语义窗；`postproduce/phrase_alignment.py`复用stable-ts估计实际WAV子句时刻，工具环境与渲染环境分开。`postproduce/word_captions.py`是该入口可选的纯派生字幕分组器，消费既有原文与字词时间估计，不调用模型、不编辑原音或估计；其源码哈希、模式和事件随当前字幕候选保存并在消费时复验，默认旧分行行为不变。旧理解发布器、V01 worker和字幕底层工具保持原实现；新层复用可验证能力，不篡改旧批准。状态与失效见[课程单元工作流](../../docs/course-unit-workflow.md)。

机械波案例按课使用独立scene，`wave_unit_shared.py`复用表现辅助、`wave_unit_model.py`保存纯科学模型。单课真实节奏返工不绑定其他课的场景文件；共享模型变化仍使全部消费者失效。冻结的早期聚合源与旧媒体仅保留追溯，不能作为新版本隐式依赖。

`postproduce/qwen_service.py`为独立GPU声音层，使用官方Qwen引擎生成内置音色WAV，限制回环监听、强令牌鉴权和单GPU任务，并绑定引擎/请求指纹缓存。`postproduce/remote_speech.py`通过既有SSH转发接收并校验音频和来源收据，不修改静音动画、不自动发布；单文件worker可部署Windows而无需迁移整个项目。状态边界和启动入口见[独立GPU配音服务](../../docs/remote-speech.md)。

`postproduce/cosyvoice_audition.py`是一次性自然度试听旁路：验证官方模型/参考哈希和请求，调用既有CosyVoice3公共API，排他保存状态、原始WAV和不可覆盖的收据。`setup-windows-cosyvoice-audition.ps1`只准备固定官方文件并排除私人speaker库；`run-windows-cosyvoice-audition.ps1`管理本次GPU占用与原Qwen任务归还，不改原环境依赖或冻结制作器。该旁路不是自动配音发布服务，生命周期及商业参考限制见配音服务文档。

`postproduce/preset_audition.py`编排Qwen五种/Kokoro八种本地中文预设同文试听；前者复用鉴权服务缓存，后者作为单文件调用独立环境的官方公共API。`templates/preset_audition.html`是离线试听页，只消费嵌入manifest与本地WAV；固定增益副本和原音分开，选择不授予发布批准。`setup-windows-kokoro.ps1`及固定requirements只创建独立Kokoro环境/官方模型清单。部署、进程、候选与长期偏好的写入者/消费者和失效规则见配音服务文档。

`postproduce/voicedesign_audition.py`提供原创中文声线选角：复用官方VoiceDesign API及原PCM/增益工具，不接参考录音。固定模型/计划/源码归档绑定每条首轮候选；打包时验证并逐字节保留旧预设原音及试听副本。`setup-windows-voicedesign.ps1`只准备经官方哈希核对的模型，`run-windows-voicedesign-audition.ps1`以专用互斥量和排他目录管理维护窗口任务，不自动停止在线Qwen，finally限时验证原服务恢复，不改外部工程。通用模板按manifest分组兼容13/23条，设计描述不是自然度评判；状态归属与失效规则见配音服务文档。

同一模块的`minimal-female`计划只补N01至N03短描述女声，`append-minimal`验证原23条全部来源/媒体后创建26条追加包，保持旧素材字节、归档旧页面与manifest。模板通过priority和kind区分排序、极简/全部设计声线筛选，不把描述目标当听感结论。运行器显式Plan/WorkerDirectory与按尝试名日志支持该独立批次，不覆写旧冻结计划；维护窗口与状态生命周期见配音文档“极简女声补测”。

Windows专用环境由`scripts/setup-windows-qwen.ps1`及固定requirements创建，模型固定revision并核验官方权重；`register-windows-speech.ps1`注册Limited配音任务。Tailscale安装器验证官方包及签名，`enable-windows-tailnet-ssh.ps1`只给当前已核验Mac增加私网SSH。`ensure-windows-tailnet-ssh.ps1`是有限开机就绪检查，由`register-windows-ssh-boot.ps1`复制到受SYSTEM/Administrators保护的目录并注册；只在指定私网地址就绪且缺少监听时重启sshd，不接触模型、讲稿或媒体。部署、启停记录与生命周期见连接说明；系统任务不等于Codex后台聊天，日常生成不依赖Codex传输。

`archive/legacy/src/manimind/experiments/sol_visual_recovery.py`只恢复有完整证据的Sol审片补帧capacity故障，保持原输入、冻结源码与审核门禁；独立短期恢复收据和分段耗时/共享额度账本不进入角色上下文，生命周期见视觉优先文档。

`experiments/sol_visual_first.py`复用三角色循环和Sol订阅传输，增加独立视觉优先路线：视觉计划与真实渲染先于讲稿，静音像素审核后才允许后写旁白，文本/源码联合复核通过后导出无音轨主片。`visual_first_data.py`提供纯数据视觉时钟、事件与讲稿绑定，`visual_first_support.py`复用既有字体和ManimGL，仅记录实际事件，不含题目图形。旧执行器不改；长期协议与来源、短期原答/阶段检查点、输出证据和静音交付分开。详细状态归属、命令和未接入最终语音的限制见 [视觉优先工作流](../reference/visual-first-workflow.md)。

## 命名规则

`postproduce/focus_captions.py`消费已批准的真实整句对齐和有声交付，生成单套烧录字幕候选，复核原声/回执/讲稿及全部来源；候选需独立真实像素审核后才能复制为正式交付。保持原画尺寸、音频码流，不附默认开启的字幕轨或同名外挂，长句拆分只声明字数比例近似。候选、字幕审核、播放交付分目录和阶段，样式、来源、字幕或模块变化失效；详见[焦点字幕后处理](../reference/focus-captions.md)。

`postproduce/lesson_opening.py`在已发布`unit_film`单套字幕正文之外增加监督片头，不改正文/旧发布器。`opening_bindings/require_opening_review/candidate/bindings/release`消费真实作者与完整来源绑定，先独立审片头再生成候选；视频stream copy并全量核对decoded帧/PTS正文后缀，原音完整PCM后缀与padding核验后一次AAC。发布实调现有content_regression合同/比较门禁，另需异比较上下文的seam/caption实际像素审核；无听审诚实标记待听审预览。长期计划和基线合同在projects，短期报告/帧在sessions，create-only候选PCM与复制交付在outputs，来源/代码/报告/媒体变化失效。精确schema、证据及接口见[片头扩展](../reference/lesson-opening.md)。

`scripts/run-windows-flexible-voxcpm.ps1`是可变句数V01首条worker的维护封装，与冻结的17句运行器分开；生成时仅worker取GPU互斥量，封装器拒绝在线/禁用的Qwen任务并保存一次尝试证据，子进程退出后重新持锁核验原服务归还，锁忙或遗弃不抢占。`flexible_voxcpm.py`可消费操作者显式核验的短期桌面GPU占用快照，精确核对设备/驱动/进程，不静默忽略未知占用。状态归属与非独占限制见[Windows桌面维护核验](../../docs/remote-speech.md#windows-桌面维护核验)。

- Python 包与模块使用 `snake_case`
- 数据模型类使用 `PascalCase`
- 配置键统一使用小写英文加下划线
- 项目 ID、镜头 ID、会话 ID 使用稳定字符串，不依赖显示标题

## 文件生命周期

- `configs/`：手工维护，长期存在
- `runtime/projects/`：项目级长期上下文，允许多次增量写入
- `runtime/sessions/`：单轮协作临时文件，可按会话清理

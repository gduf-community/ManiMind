## 白名单同步

使用 [sync-thirdparty-assets.ps1](../../scripts/sync-thirdparty-assets.ps1) 同步，脚本只复制白名单内容，不复制完整上游仓库。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\sync-thirdparty-assets.ps1
```

若源目录不在仓库根目录，可显式传入：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\sync-thirdparty-assets.ps1 `
  -HtmlSkillSource "<AI-Animation-Skill-main 的实际路径>" `
  -HyperframesSource "<hyperframes-main 的实际路径>"
```

同步完成后，允许删除外层开源仓库目录，只保留 `resources/` 内精简资产。

## ManimGL 接入

- 默认渲染引擎改为 3Blue1Brown 上游的 `manimgl` 包，安装与 API 依据来自 `https://github.com/3b1b/manim`。
- 本仓库只实现 CLI 调用、输出路径、后端选择与审核证据编排，不复制 `manimlib` 内部实现。
- `resources/skills/manim/SKILL.md` 来源是 ManimCE 工作流，与 ManimGL API 不兼容，因此保留作兼容后端参考，未修改第三方文件内容。
- 项目本地环境固定在 `manimgl_env/` 并由 `.gitignore` 排除；`scripts/setup-manimgl.ps1` 是可复现安装入口。
- macOS 使用 `scripts/setup-manimgl.sh`：Python 与渲染依赖写入同一项目环境，Apple Silicon 的 `ffmpeg/ffprobe` 由 `static-ffmpeg` 提供，公式工具链使用用户目录下的 TinyTeX。脚本只建立本地环境和符号链接，不复制这些第三方项目的内部实现。

## ClaudeCode 抽取策略

- `ClaudeCode/` 仅作为“参考源码压缩包”，不属于运行时硬依赖。
- 可学习并落地的内容优先放入 `src/manimind/`：
  - 角色编排约束（只读探索、只读规划、验证专用角色）
  - 上下文装配策略（按角色和阶段注入、可缓存提示词分段）
  - 任务状态机与阻塞依赖（包含验证关卡）
- 抽取映射见 [ClaudeCode抽取清单.md](../../archive/legacy/docs/ClaudeCode抽取清单.md)。

## 维护原则

1. 只保留直接服务当前项目编排与渲染任务的资产。
2. `resources/` 下资产视为“裁剪后的第三方内容”，与 `src/manimind/` 自研编排逻辑分离。
3. `ClaudeCode/` 可删除，删除前需确认其可复用能力已在 `src/manimind/` 和文档内沉淀。
4. 白名单变更必须同步更新本文件与同步脚本。

## HyperFrames 渲染引擎（Canvas 主舞台）

`resources/references/hyperframes/` 只收文档与技能；实际调用的引擎由 `tools/hyperframes/package.json` 锁定（hyperframes 0.9.43、gsap 3.14.2、katex 0.19.1，均为 2026-11-28 时已发布满两周的版本），在该目录运行 `npm ci` 安装，`node_modules/` 不入 Git。

- 调用入口：`python -m manimind.canvas.render`，不直接散落 `npx hyperframes`。
- 隐私：每次调用设置 `DO_NOT_TRACK=1`、`HYPERFRAMES_NO_TELEMETRY=1`、`HYPERFRAMES_NO_UPDATE_CHECK=1`、`HYPERFRAMES_NO_AUTO_INSTALL=1`、`HYPERFRAMES_NO_OPTIONAL_INSTALL=1`，并从渲染尝试目录启动（HyperFrames 会读取当前目录的 `.env`）。不改用户级 `~/.hyperframes/config.json`。
- 浏览器：`HYPERFRAMES_BROWSER_PATH` 指向锁定的 chrome-headless-shell（默认取 Playwright 缓存 chromium_headless_shell-1234，即 151.0.7922.34，可用 `MANIMIND_CANVAS_BROWSER` 覆盖），版本写入回执。macOS 本地不支持 BeginFrame，HyperFrames 自动改用截图模式；确定性由仓库自己的检查验证。
- FFmpeg：通过 `FFMPEG_PATH`/`FFPROBE_PATH` 指向 `manimgl_env/bin`（只设 PATH 时 HyperFrames 找不到）。
- 音频：HyperFrames 混音会把增益整体抬高约 2.7 dB、峰值超过满幅，不符合恒定增益与峰值规则，所以只用它渲染静音画面。

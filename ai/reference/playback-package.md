# 播放交付

已烧录字幕的视频不应与同名 SRT 一起作为默认播放包交付：部分播放器会自动载入外挂字幕，和画面字幕叠加。制作与审核档案保留原样，播放目录只放 MP4 与来源清单。

## 入口

```sh
PYTHONPATH=src manimgl_env/bin/python -m manimind.postproduce.playback_package \
  --delivery sol61=outputs/sol61-team-20261023/delivery.json \
  --delivery deepseek=outputs/deepseek-team-20261023/delivery.json \
  --output outputs/playback-single-subtitle-20261023
```

这是针对已确认烧录字幕试片的显式导出工具，不自动判断视频是否有画面字幕，也不自动接管冻结实验的合成命令。目标目录必须不存在。工具核对发布视频哈希、原审核哈希、审核批准与已记录的完整解码结果，并要求一个视频流、一个音频流、无软字幕流；逐字节复制后再次核对媒体与来源证据。它不能证明原审核的身份真实性或教学效果。

## 状态与边界

| 产物 | 写入者 | 消费者 | 生命周期 | 失效条件 |
| --- | --- | --- | --- | --- |
| `outputs/<export-id>/*.mp4` | 播放打包器 | 播放器、观众 | 单次交付保留，不覆盖 | 与来源交付哈希不同 |
| `outputs/<export-id>/manifest.json` | 播放打包器 | 观众、审计者 | 与播放副本共同保留 | 视频、来源交付或审核哈希改变 |

不新增长期事实或临时创作记录，不向作者提供反馈，不调用模型，不修改内容、不重新批准。失败时不会写出成功清单；留下的部分目录不能当成交付成功。字幕附件仍在来源实验目录，需要时单独取用，不放入默认播放目录。

## 2026-10-23 排查

Sol 和 DeepSeek 三角色版本的最终 MP4 均只有 H.264 视频和 AAC 音频；直接解码抽查的原始帧只见一层字幕。两目录同时含有 `projectile-story.srt`，具备自动载入后叠加的条件。播放器自动加载是当前有证据支持的原因推断，并非已检查用户实际播放器设置；若独立 MP4 仍重叠，应进一步检查播放器自动字幕/翻译，并取得具体时间点的画面。

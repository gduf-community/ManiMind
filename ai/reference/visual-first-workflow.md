# 视觉优先工作流

## 目标与范围

后续新项目使用[理解优先v2](../../docs/understanding-workflow.md)。本页继续记录冻结v1的历史契约，不将旧批准自动升级为新的编辑质量或整句同步批准。

先打磨知识演示，再制作最终声音。2026-10-24新增独立入口 `experiments/sol_visual_first.py`，保留旧配音先行流程、冻结实验和成片，不中途改写它们。本轮主控、创作和独立审片均使用GPT-6.1 Sol max的临时订阅CLI上下文，不输入旧稿、旧片、主对话或其他作品的修改意见。

当前交付是**静音动画主片、后配音讲稿、实测视觉事件与审核记录**。不调用现有机械TTS，不声称已经接入开源语音模型，也不把无声主片包装成最终配音成片。后续语音选型、实际合成、音画对齐、字幕及听审是另一阶段，不能用当前文本审核替代。

## 执行顺序

1. 主控依据公开受众、目标和科学条件设计视觉计划，只给视觉段落、时长、用途和自命名事件，不先合成旁白。
2. 创作者自主写ManimGL场景，复用字体/数字/公式工具。模型的物理时间不由播放时间或语言长度决定。
3. 渲染器执行当前源码，记录视觉事件实际发生的时刻，输出不带音频轨和朗读字幕的原始视频；原分辨率抽帧和0.5秒时序联系表交给创作者及主控。
4. 主控先检查当前每一段像素，再请求新上下文审核。首看只接收公共任务、段落边界与实际像素，不给作者设计解释、源码或讲稿。保留必要标签、公式和短图示；并非要求所有抽象知识都能脱离语言解释。
5. 静音视觉审核通过后，主控才能写后配音讲稿。每段语言绑定实测事件及before/during/after关系，不把该关系当成已测量的语音秒数，不修改视觉时间轴。
6. 另开新上下文审核源码、科学模型、事件、当前画面和后写讲稿。视觉或讲稿有问题则返回原始意见，由模型自行返工；协调器不代写内容。
7. 两道审核与原答来源、媒体哈希全部匹配后，逐字节导出静音播放主片，并执行全片解码。最终声音仍为not_generated。

修改视觉计划、源码或重新渲染会清空双方看图覆盖，撤销视觉与讲稿批准，并把后写讲稿归档。只修改后配音文本保留未变的视觉批准，但撤销讲稿批准。原始记录不删除；单次调用和媒体故障不自动重发，未决检查点需明确检查。

## 通用层而非题目模板

`visual_first_data.py`只处理视觉时钟、事件完整性、后写讲稿绑定与现有源码安全检查的适配。`visual_first_support.py`只复用原生ManimGL及既有中文字形支持，以`mark(event_id)`记录实际时间；没有平抛图形、预设分镜或课程答案。`sol_visual_first.py`复用原三角色协作循环、订阅请求、沙箱、真实抽帧、审核结构自修复、固定学习量表与订阅额度观察器，不重写渲染引擎。

创作风格、镜头数量与视觉节奏由模型决定。总分至少80，科学、因果、视觉解释和节奏各至少3/4；严重问题不可被总分抵消。这是内部编辑量表，不是学生效果结论。完成当前样片也不等于证明新流程一定优于配音先行。

## 状态归属

| 状态 | 写入者与消费者 | 生命周期与失效 |
| --- | --- | --- |
| `runtime/projects/<id>/isolation.json`、`collaboration-protocol.json`、`runtime-adapter.json` | 初始化器/角色、审计者 | 首次调用前冻结；配置、profile、源码漂移停止运行 |
| 同目录`authorship.json`、`narration-authorship.json` | 模型原答机械提取器/来源校验、审核 | 对应当前视觉计划或后配音稿；原答、时钟、事件或文本改变失效 |
| `runtime/sessions/<id>-generation/team-state.json` | 三角色执行器/下一角色、审核门禁 | 当前尝试；visual_phase区分visual_draft、visual_revision、visual_approved、narration_draft、narration_revision、narration_approved和silent_delivered；输入变化按上述规则撤销批准 |
| 同目录`agent-state.json` | 工具执行器/取证与来源检查 | 保存渲染次数、当前收据及观察；新视觉输入或渲染使旧观察失效 |
| 同目录`launcher.json`及角色`request-*` | 后台启动器、订阅传输/防重复与费用审计 | 收据只对当前进程有效；原始请求与失败永久保留，不作为再次收费授权 |
| `outputs/<id>/spec.json`、`timeline.json` | 主控视觉计划的机械提取器/创作者、渲染器 | 只有视觉时钟；计划变化撤销后续媒体与讲稿 |
| 同目录`visual-events.json` | 真实渲染运行时/后写讲稿、审核 | 记录实际事件时间；新源码、计划或渲染失效，禁止只声明预计时间冒充实测 |
| 同目录`review-input.json`、原帧与时序联系表 | 取证器/角色、独立审核 | 当前实际视频；哈希变化撤销批准 |
| `runtime/sessions/<id>-independent-review/cycle-*` | 独立审核传输/主控、发布门禁 | 分开视觉首看与后配音文本复核；任一未通过不能导出正式主片 |
| `outputs/<id>/narration-plan.json` | 主控原答加实测锚点/后续语音阶段 | 文本与语义关系，不是音频排程；视觉事件或文本变化需再审 |
| 同目录`playback/visual-master.mp4`与`delivery.json` | 审核后发布器/用户、未来语音阶段 | 不可覆盖的静音交付；来源、文本或视频变化失效；不含最终声音批准 |
| 长期额度快照、短期原始采样、输出费用/耗时 | 只读观察器与报告器/用户、成本审计 | 本轮制作；账户共享、刷新或其他聊天使单片周额度归因失效 |

## 运行

```bash
PYTHONPATH=src manimgl_env/bin/python -m manimind.experiments.sol_visual_first \
  --config configs/sol61-visual-first-20261024.json --background
```

只初始化用`--initialize-only`；仅对完整已收且未执行工具的原答使用`--resume-received-request`，不重发未知收费请求。后台启动需新建、未锁定且无未决操作的ready状态。工程小样用于验证无音轨、实测事件与渲染链，不算模型生成作品。

## 审片故障续跑

`experiments/sol_visual_recovery.py`是独立技术恢复入口，不改既有冻结执行器。只接受已收到主控`request_review`、首看者已要求补帧、补帧详情调用被服务端明确以capacity拒绝的检查点；逐项核对原答、输入、模型/强度、图片、媒体和源码。原样重发失败的详情输入，不重做首看、创作或渲染，不添加编辑意见。真实审核通过或返工结论均原样回填当前轮，再交回原三角色循环；没有审核批准不能发布。

先用`--check-only`只读检查，再执行：

```bash
PYTHONPATH=src manimgl_env/bin/python -m manimind.experiments.sol_visual_recovery \
  --config configs/sol61-visual-first-20261024.json
```

短期`<id>-generation/review-recovery/`由恢复器独占写入，保存原状态/账本快照、恢复器指纹、进程和授权收据、续跑前后账户快照；消费者是操作员和审计。一次明确恢复尝试后不自动再次收费，进程退出或任何绑定哈希变化使恢复许可失效，未知请求不得重发。原始失败和未知用量永久保留。`outputs/<id>/recovery-accounting.json`由恢复器结束时写入，消费者是成本报告与用户；分开停机前和续跑耗时、排除停机间隔，保留原额度区间，不将两个账户区间相减或归因单片。恢复器本身不进入任何创作/审核上下文。

## 选声后的配音阶段

2026-10-25用户选择VoxCPM2试听V01后，新增独立的[本地完整配音阶段](../../docs/remote-speech.md#选定-v01-后的完整配音)。`voxcpm_narration.py`以该AI样音为参考逐句合成；`visual_narration.py`重新验证本页静音及讲稿批准、保持原文和物理时钟，按实测完整WAV与事件排程，经过新的独立时序审核才混音和封装。不修改本实验冻结执行器、原主片或旧批准，也不把原文本审核追认为实际声音通过。主片码流直接复制，只有视频/音频两轨，无内嵌/烧录/同名外挂字幕，可选SRT另存support；未听审和学生测试仍明确保留。

## 借鉴与限制

借鉴[Motion Canvas事件时序](https://motioncanvas.io/docs/time-events/)将语义事件与绝对秒数解耦，及[Manim Voiceover占位/正式录音分阶段](https://voiceover.manim.community/en/stable/quickstart.html#record-your-own-voiceover)的工作方式；未复制第三方实现或资源。此冻结静音实验本身不包含音频对齐器、开源语音后端或最终字幕生成，后续新增能力位于上节独立配音阶段；若需改句或局部停留，应重新审核，避免靠整片变速、改变物理规律或无限补尾帧迁就配音。静音审核是同模型异上下文的抽帧审核，不是连续观看、听审或学生理解测试。
